# 批次查询与创建接口 实现计划

> **目标：** 实现评测运营中心页的五个查询接口（列表、统计卡、计划卡、评估对象名单、失败明细）与一个创建接口（发起手动定向分析），挂载路由并完成 Wire 装配，前端可直接消费。
> **架构：** service 层承载 stalled 派生、target_brief 摘要、占比计算与 B1 校验（1601/1602/1603 错误码），handler 按 account 样板走 handleServiceError 映射。列表接口的评估对象摘要与计划卡的维度计数为只读聚合，创建接口同步落批次记录后异步入队。
> **技术栈：** Go 1.25、Gin、GORM（经仓储接口）、userapi 客户端（计划卡全员计数）
