## 探索发现的关键实现差异（影响测试断言）
1. 评估对象互斥用 radio（全员/指定人员）+ 指定人员多选按钮，非 spec 描述的多选下拉。指定人员按钮在全员态 disabled，切到指定人员态可点。
2. 触发日与评估区间当前存在 i18n 渲染缺陷：切周期后这两列显示原始 key（如 `systemParams.triggerDay.weekly`）而非中文文案。根因 period.ts 返回嵌套 key，组件用 t(key) 渲染对象类型 key，i18next 返回 key 字符串。测试按 spec 正确文案断言，用于暴露该缺陷。
3. 模型列表底部统计文案实际为「共 N 个模型，当前启用：{名称}」「平台所有 AI 调用都走该模型」（spec 写「平台所有 AI 调用走该模型」，措辞略异）。
4. 连通验证与集成密钥临时查看在未配置态 disabled（spec 规则5 / 4.2.5 一致）。

## 页面对象

测试拆为两个页面对象：SystemParamsPage（系统参数页）与 LlmConfigPage（大模型配置页 + 三个弹窗）。

### SystemParamsPage 定位器
- `periodSelect`：周期长度 Select（getByRole combobox name 周期长度，shadcn Select 触发器）
- `triggerTimeInput`：触发时点（getByRole textbox name 触发时点 / id config-trigger-time）
- `triggerDayText`：触发日只读文本（Label「触发日」的相邻只读 div）
- `intervalText`：评估区间只读文本（Label「评估区间」的相邻只读 div）
- `targetAllRadio`：全员 radio（getByRole radio name 全员）
- `targetSpecifiedRadio`：指定人员 radio（getByRole radio name 指定人员）
- `memberSelectButton`：指定人员选择按钮（getByRole button name 点击选择指定人员）
- `resetButton`：恢复默认（getByRole button name 恢复默认）
- `saveButton`：保存配置（getByRole button name 保存配置）

### LlmConfigPage 定位器（含弹窗）
- 模型列表区：`searchInput`（name 搜索模型名称或模型 ID）、`addButton`（name 新增模型）、`table`、底部统计文本
- 模型行操作：按模型名称所在 row 定位行内 查看/编辑/删除 按钮、启用 switch、查看 API Key 明文 按钮
- 新增/编辑弹窗 dialog：模型名称/模型 ID/API 地址 textbox、服务商 combobox、API Key 密码框 + 显隐、确认新增/保存修改、取消
- 查看弹窗：标题「查看模型·{名称}」、API Key 明文区、复制 Key、编辑模型、关闭
- 集成密钥卡片：配置状态文本、显示明文按钮、配置/更新按钮、连通验证按钮
- 集成密钥更新弹窗：新集成密钥密码框、确认配置/确认更新、取消
- toast：sonner，用 page.getByText(文案) 断言（DOM 为 [data-sonner-toast]）

## 数据策略分析
- 周期长度/触发时点/评估对象：类型 A（测试者输入，无唯一性）
- 模型名称：类型 A（无唯一性约束，spec 未要求模型名称唯一）
- 模型 ID/服务商/API 地址/API Key：类型 A
- 模型主键 ID（雪花）：类型 D3（服务端生成，afterAll 清理需用，通过 GET /api/llm-configs 查询业务键定位 id 再 DELETE）
- 集成密钥值：类型 A（测试者输入）
- 唯一性：spec 全程无任何字段要求唯一性校验，故无类型 B、无唯一性测试组

## 测试场景

> spec 明确系统无角色概念、平台账号统一全权，故无权限/多角色测试组。spec 无字段唯一性约束，故无唯一性测试组。

### 7. 新增/编辑模型弹窗 - 校验
#### 7.1 新增必填字段留空提交应失败
**需求来源**: 4.3.2 模型名称/服务商/模型 ID/API Key（新增）必填
**验证点**: 不填必填字段点确认新增，字段内联报错，弹窗不关
**数据清理**: 无（未提交）

#### 7.2 字段长度边界
**需求来源**: 4.3.2 模型名称≤50、模型 ID≤100、API 地址≤500（可选 URL 格式）、API Key≤200
**验证点**: 模型名称输入 50 字符成功、51 字符报错；模型 ID 100 成功/101 报错；API Key 200 成功/201 报错
**数据清理**: afterAll 删除创建成功的边界记录

#### 7.3 API 地址非 URL 格式应报错
**需求来源**: 4.3.2 API 地址校验「填写则 URL 格式」
**验证点**: 填非 URL（如 plain-text）提交，字段报错；留空不报错
**数据清理**: 无
