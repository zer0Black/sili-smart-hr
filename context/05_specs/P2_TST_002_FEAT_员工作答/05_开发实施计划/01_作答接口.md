# 作答接口 实现计划

> **目标：** 员工作答域后端三接口（A1 上下文 / A2 逐题回复 / A3 提交）全链贯通：建表、仓储、服务（令牌校验链 + F7 契约消费）、公开路由挂载与 Wire 装配。
> **架构：** 按 account 四层样板新增 answer 域（domain → repository → service → handler → router → wire）。令牌校验链为三接口共享私有路径；状态推进全部经 F7 `AssessmentTestTaskService` 既有契约（StartSession/CompleteTask）进程内直调，answer 域不写 F7 三表。三接口挂公开路由组（与 /api/login 同层）+ IP 限流 30/min。
> **技术栈：** Go 1.25 + Gin + GORM（AutoMigrate）+ Wire；SHA-256 哈希点查（标准库 crypto/sha256）；Redis 限流复用既有 middleware.RateLimit。
