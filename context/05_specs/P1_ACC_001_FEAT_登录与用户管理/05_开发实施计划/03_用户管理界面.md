# 用户管理界面 实现计划

> **目标：** 在前端落地用户管理列表页与新增/编辑/重置密码/删除弹窗，接通顶部导航，密码入口经 RSA-OAEP 加密提交，全部文案中英双语。
> **架构：** 沿 account feature 三件套扩展（api/hooks/types）+ lib/contracts 契约；列表页挂 _authenticated 路由 /system/users；弹窗下沉 features/account/components；复用子计划1 的 crypto.ts 加密密码；NavMenu 用户管理项接通为可点链接。
> **技术栈：** TanStack Router 文件路由 + TanStack Query + react-hook-form/zod + shadcn/ui（dialog/switch/table/badge/alert-dialog）+ i18next。

---
