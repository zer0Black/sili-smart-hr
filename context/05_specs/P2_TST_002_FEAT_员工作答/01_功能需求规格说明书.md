## 1. 概述

### 1.1 功能背景

主动测试的运营链路（P2_TST_001）已闭环：运营发起测试生成一次性作答链接并手动分发，任务状态机、逾期判定与 AI 阅卷引擎全部就位，但阅卷链路缺触发路径：员工侧的作答页仍是 B 档占位页，员工拿到链接后无处作答，任务停留在待作答/已逾期/已取消三态，CompleteTask/StartSession 服务契约（F7 已实现并声明归 F8 调用）无调用方，阅卷输入所依赖的作答对话记录无落库方。

员工本人不是平台用户（决策 3、6），无平台主入口，仅有一个经一次性链接进入的轻量作答页，提交后链接即失效。作答页与主平台 JWT 物理隔离，一次性令牌鉴权（T1 已建鉴权基座概念）。

### 1.2 本功能业务目标

1. 作答入口可达：员工点击运营分发的一次性链接（/answer/{token}）进入作答页，令牌校验通过即可作答，无账号登录、无身份核验表单，零额外摩擦（决策 6 轻量口径）。
2. 对话式施测：员工与 AI 逐题对话完成作答（决策 17）：AI 管理能力题呈现情境与作答要求（选项为自然文本），员工回复所选选项与理由；九型人格量表题逐条呈现陈述，员工回复 1-5 数字。规则化推进，无 LLM 调用。
3. 断点可续：作答逐题实时落库，员工中途退出后经同一链接重进，已完成对话恢复、从断点继续（与 F7 进行中任务到期顺延、链接对已建立会话保持可用的口径互为支撑）。
4. 提交即闭环：全部题目作答完成后员工提交，任务推进（F7 CompleteTask 契约：任务已完成、链接已使用、阅卷任务投递）单事务落库（作答记录已逐题实时落库，提交无终态化动作），提交后链接失效、作答页转为成功态。

### 1.3 与 PRD 拆分的对应关系

本 feature 即 PRD 5.2.2 的 F8（员工作答），承载 PRD 4.3 员工作答的 1 个功能点（测评作答：进入作答页、AI 逐题对话施答、提交作答）与 PRD 4.14 对外接口的作答提交接口功能点（作答数据接收）。页面落点为独立路由 /answer/$token（挂路由根、不套 _authenticated 布局），测试任务的发起与运营归 F7（P2_TST_001）；阅卷评分归 F7 已建的 grading 引擎（本功能只投递触发）；画像呈现归 F9/F10。

## 2. 角色与权限矩阵

> **说明**：本章节整合所有权限信息，是权限控制的**单一真实来源**。第4章各页面的权限要求均引用本章节，避免重复定义。

### 2.1 数据权限（行级访问控制）

| 角色 | 数据范围 | 说明 |
|------|---------|------|
| 被测评员工 | 仅令牌指向的单个任务 | 持有效一次性令牌只能访问该任务的作答内容（元信息、题目、自己已产生的对话记录），提交作答；无任务列表、无他人任务、无阅卷结果可见性 |
| 平台账号（已登录） | 无 | 平台账号不进入作答页，作答页不挂 JWT，平台侧对本功能无访问面（运营侧链路归 F7） |

**数据范围说明：**
- 令牌即权限边界：随机不可预测令牌加单次有效语义（F7 5.1.4 规则1，形态为 base64url 43 字符，出处 F7 04 模型文档 §3.2），任何持有有效链接者可作答，无二次身份核验（已确认口径：链接经 IM/邮件私密分发，接受转发代答风险）。
- 作答页与主平台 JWT 物理隔离：不读 auth store、不带 Authorization 头、不触发 401 登出链路，作答接口挂公开路由组（与 /api/login、/api/setup 同层，非 JWT 鉴权组）。

### 2.2 页面访问权限

| 页面名称 | 可访问角色 | 可操作角色 | 字段级权限（如有） |
|---------|----------|----------|------------------|
| 作答页（/answer/$token） | 持有效令牌者（员工） | 持有效令牌者（员工） | 无 |
| 作答页失效态 | 任何打开链接者（只读呈现） | 无操作 | 无 |
| 作答页成功态 | 提交成功的员工（页面内转换呈现，重开链接为失效态） | 关闭窗口（纯浏览器行为，无业务操作） | 无 |

**权限说明：**
- 令牌校验失败（不存在、已使用、已失效、任务已取消/已完成）不进入作答界面，页面呈现失效态文案与指引，不泄露任务对象姓名等细节（防枚举语义，令牌不存在与令牌失效同文案）。
- 运营重发作废旧令牌后，旧链接打开同样呈现失效态（F7 4.1.4 规则1：旧链接立即失效）。

## 3. 页面与功能总览

### 3.1 页面清单

| 序号 | 页面名称 | 页面形式 | 职责说明 | 包含功能 |
|-----|---------|---------|---------|---------|
| 1 | 作答页 · 作答态 | 独立页面（挂路由根，一次性令牌鉴权） | 承载员工对话式作答全过程：元信息展示、作答须知、逐题对话、进度呈现 | 进入校验、AI 逐题对话施答、断点恢复 |
| 2 | 作答页 · 失效态 | 独立页面（同路由的状态分支） | 令牌不可作答时的呈现与指引 | 无操作（文案呈现） |
| 3 | 作答页 · 成功态 | 独立页面（同路由的状态分支） | 提交成功后的结果呈现 | 关闭窗口 |

**页面形式说明：**
- 三个形态是同一路由 /answer/$token 按令牌校验结果与作答进展切换的页面状态，非三个独立路由。
- 页面挂路由根（__root 下与 /login、/setup 并列），刻意不套 _authenticated 鉴权布局、不带主平台顶栏（PRD 4.3：独立于主平台框架，视觉风格保持一致但布局独立）。品牌头（logo、平台名、员工作答副标题）随原型同构，无导航、无 demo 切换器（原型中的演示切换器为原型专属，实际页面不出现）。

### 3.2 页面跳转流程

```
[入口：运营分发的 IM/邮件链接] → [作答页 · 作答态]
    ├── 首次进入 ——令牌校验+会话上报（StartSession）——→ AI 开场白 → 逐题对话
    ├── 中途退出后重进 ——拉取已有对话——→ 断点续答
    └── 全部作答完成 → 点击「提交并结束」——提交落库+CompleteTask——→ [作答页 · 成功态]

[失效令牌链接] → [作答页 · 失效态]（文案指引联系运营，无操作）
```

**流程说明：**
1. 员工点击链接进入作答页，令牌校验通过即上报会话（F7 契约 StartSession：任务待作答转进行中），页面呈现测评元信息、作答须知与 AI 对话区，AI 发出开场白与第一题。
2. 员工在对话框逐题回复，AI 确认后进入下一题；中途关闭页面后重新打开同一链接，已完成对话恢复，从断点继续。
3. 全部题目作答完成后，输入区转为「提交并结束」按钮，员工点击提交，成功后页面转为成功态（结果说明、任务号、关闭窗口）；提交后链接失效，再打开同一链接呈现失效态。

## 4. 页面功能详细说明

### 4.1 页面 1：作答页 · 作答态

#### 4.1.1 页面概述

**页面形式：**独立页面，挂路由根，一次性令牌鉴权（令牌取自 URL 路径参数）。

**页面职责：**承载单个测试任务的对话式作答全过程。员工经运营分发的一次性链接进入，是主动测试在员工侧的唯一入口；作答记录在此产生并落库，作为 F7 阅卷引擎的输入载体。

**页面结构（原型同构）：**品牌头（logo + 平台名 + 综合人才测评平台·员工作答副标题）→ hero 区（类型标签、测评标题、用途说明、元信息行：预计用时/题量）→ 卡片主体（作答须知、对话进度、AI 对话区）。

#### 4.1.2 涉及字段

**A. 测评元信息（页面加载时从作答页数据接口获取，只读展示）**

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 业务含义 |
|---------|---------|---------|---------|--------|
| 类型标签 | 标签 | 数据库（任务 test_type 映射：ai_mgmt 为 AI 对话测评，enneagram 为标准量表） | 页面加载 | 测评类型标识 |
| 测评标题 | 文本 | 系统预设（按 test_type：AI 管理能力测评 / 九型人格测评） | 页面加载 | 测评名称 |
| 用途说明 | 文本 | 系统预设（按 test_type 固定文案，含参考性口径：九型结果仅供参考不作为绩效评价） | 页面加载 | 员工认知测评目的 |
| 预计用时 | 文本 | 系统预设（按 test_type：ai_mgmt 约 25-30 分钟，enneagram 约 10-15 分钟） | 页面加载 | 作答时长预期 |
| 题量 | 文本 | 数据库（任务题目快照的题目数） | 页面加载 | 共 N 题 |
| 作答须知 | 文本（标题+条目列表，系统预设 3 条，见 3.3 线框） | 系统预设 | 页面加载 | 施测方式与作答约束的告知（逐题回复即推进、不可回改、结果不在此页展示） |

**B. 对话区字段（作答过程实时渲染）**

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---------|---------|---------|---------|---------|--------|--------|
| AI 消息 | 气泡文本 | 数据库（题目快照经 ID 现读的题目文本，按对话剧本包装） | 每题推进时 | 无（只读） | — | 逐题呈现：AI 管理能力题为「第 X 题 · 子能力名 + 情境 + 作答要求（含选项全文）」，九型为「第 X 题：题项陈述 + 1-5 级作答说明」 |
| 员工回复 | 多行文本输入 | 用户输入 | 员工发送时 | 非空（去首尾空格后）；ai_mgmt 上限 500 字符；enneagram 须为 1-5 的整数 | 空 | 员工对本题的作答 |
| 对话进度 | 单行进度（计数+细进度条） | 前端计算（已答题数/总题数） | 每题确认后 | 无 | 0/N | 已完成 X / N（单行呈现，与进度条同一通道） |

**C. 提交确认（全部题作答完成后呈现）**

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 业务含义 |
|---------|---------|---------|---------|--------|
| 任务号 | 文本（等宽字体） | 数据库 | 提交成功后（成功态） | 员工与运营沟通的引用锚点（T/E 前缀） |

#### 4.1.3 功能与按钮

**用户可操作功能：**

- **进入作答页（令牌校验）**
  - 触发方式：打开链接（无按钮）
  - 按钮级别：不适用（页面加载行为）
  - 权限要求：持有效令牌者
  - 加载状态：是，校验期间整页 loading
  - 功能说明：以 URL 令牌校验任务可作答性（任务存在、链接 valid、任务状态 pending 或 in_progress）。通过即调 F7 StartSession 契约（幂等）并拉取作答数据（元信息、题目全集、已有对话记录）；首次进入对话区从开场白与第一题开始，重进从断点续答。校验不通过转失效态（4.2）。

- **发送回复**
  - 触发按钮：发送
  - 按钮级别：页面级（对话输入区）
  - 按钮位置：输入框右侧
  - 触发方式：点击按钮或输入框内回车（Shift+回车换行）
  - 权限要求：持有效令牌者
  - 加载状态：是，发送中输入区禁用（AI typing 气泡呈现）至接口响应
  - 功能说明：校验通过后将本条回复落库（作答对话记录新增一行），按规则推进：九型回复合法（1-5 整数）即确认本题、进入下一题；不合法则 AI 提示重答、停留本题（不落无效记录）；ai_mgmt 回复非空即确认本题。已到最后一题时进入完成待提交态，输入区转为提示文案与「提交并结束」按钮。

- **提交并结束**
  - 触发按钮：提交并结束
  - 按钮级别：页面级（对话输入区位置）
  - 按钮位置：输入框原位替换
  - 触发方式：点击按钮
  - 权限要求：持有效令牌者
  - 加载状态：是，按钮 loading 至接口响应
  - 功能说明：提交作答，单事务驱动任务侧终态化（作答记录已逐题落库、无终态化动作，5.3.4 规则3）：调 F7 CompleteTask 契约（任务转已完成、链接置已使用、阅卷任务投递，投递失败整体回滚）。成功后页面转成功态；失败 toast 提示原因留在作答态可重试提交。

**前端自动流程：**

- **会话上报**
  - 触发时机：令牌校验通过进入作答态时（含重进）
  - 说明：调用 F7 StartSession 服务契约，任务待作答转进行中（幂等，进行中任务重复调用无副作用）。上报使 F7 逾期 tick 对本任务顺延（进行中任务到期不强制逾期），员工重进链接保持可用。

- **对话恢复**
  - 触发时机：重进作答页（令牌仍有效、任务进行中）时
  - 说明：拉取已有作答对话记录按序渲染消息流，进度与当前题从记录推算，从断点继续。已提交（任务已完成）的任务重进呈现失效态。

#### 4.1.4 业务规则

- **规则1：规则化施测（对话剧本）**
  - 规则描述：AI 逐题发问为服务端状态机驱动的规则化包装，无 LLM 调用：按题目快照顺序逐题呈现题目全文（经题目 ID 现读），员工每题一次回复即推进一题；AI 消息文案为系统预设剧本（开场白、题目包装、题间确认、完成提示），按当前题号生成，不随员工回复内容变化。
  - 触发条件：进入作答页、每次发送回复。
  - 约束说明：作答完整性判断为服务端格式校验（ai_mgmt 非空、enneagram 1-5 整数），无语义判断；追问、澄清、跳题均不提供（选项写在作答要求文本中、员工一次回复说明选项与理由，决策 17 口径）。

- **规则2：逐题落库与断点恢复**
  - 规则描述：每条员工回复实时落库（一行一回复，含题号与回复内容），对话进度以落库记录为准；员工中途退出重进，按记录恢复到断点（下一未作答题）。
  - 触发条件：每次发送回复成功。
  - 约束说明：作答对话记录是阅卷输入载体（全过程对话非仅最终选项，F7 5.2.3）；同一题的多次合法回复不覆盖（每次合法回复推进题号，理论上同题仅一条合法回复；九型非法回复不落库）。

- **规则3：提交事务性**
  - 规则描述：提交为单事务，完整流程与守卫口径归 5.3（作答记录无终态化动作，事务只驱动任务侧三步推进）。
  - 触发条件：点击提交并结束。
  - 约束说明：不存在提交成功但阅卷未投递的中间态（F7 5.2.5 口径）；提交幂等守卫由 F7 条件更新承载（completed/canceled 终态拦截），重复提交第二次被拦、页面仍转成功态。

- **规则4：令牌一次性与失效呈现**
  - 规则描述：提交成功后链接失效（已使用）；运营重发/取消后旧链接失效（已失效）；到期未提交链接失效且任务已逾期（待作答任务到期即逾期，进行中任务顺延）。失效链接打开一律呈现失效态。
  - 触发条件：提交、重发、取消、到期。
  - 约束说明：失效态不区分失效原因细节、不展示任务对象信息（防枚举：不存在与失效同文案）；文案指引员工「请联系测评发起人重新获取链接」。

- **规则5：作答中任务被运营处置**
  - 规则描述：员工作答中（进行中）任务被运营取消：链接立即失效，员工下一次交互（发送回复或刷新页面）被拦转失效态，已产生的对话记录保留（阅卷不触发，作答未提交的取消任务停留待阅卷，F7 口径）。
  - 触发条件：作答期间任务被取消。
  - 约束说明：作答页不做轮询主动感知取消，交互时校验兜底；员工无感知窗口最长为一次交互间隔。

#### 4.1.5 交互逻辑

- AI 消息呈现带 typing 气泡过渡（三点动画），题目消息分多段呈现（题号行、情境段、作答要求段，原型同构）；消息流自动滚动到底部。
- 对话进度（单行计数+进度条）在每次确认本题后即时更新；完成待提交态输入区转为提示「本次作答已完成，可提交结束」与提交按钮。
- 九型数字回复非法（非 1-5 整数）时 AI 剧本提示「请回复 1 到 5 之间的数字」，输入框保留员工输入便于修正。
- 页面移动端响应式（原型同构：窄屏收起 hero 图标与副标题、对话区高度适配）。
- 提交成功态呈现结果说明（作答已提交、链接已失效、结果不在此页面展示、可关闭窗口）、任务号与「关闭窗口」按钮；window.close 失效时提示手动关闭标签页。

#### 4.1.6 权限要求

参见第2.2节「页面访问权限」。特殊说明：作答接口全部挂公开路由（令牌自证），与主平台 JWT 体系无交集，前端作答页专用请求通道不读 auth store、不触发 401 登出跳转。

## 5. 非页面功能详细说明

### 5.1 作答页数据组装（令牌校验与会话建立）

#### 5.1.1 功能概述

**触发方式：**API 调用（作答页加载）
**触发时机：**员工打开 /answer/{token} 链接
**功能职责：**令牌校验、会话上报（F7 StartSession）、作答上下文组装（元信息、题目全集、已有对话）。

#### 5.1.2 处理流程

1. 接收令牌，按哈希点查链接行（F7 链接表 token_hash 列），校验：链接存在且状态 valid、所属任务状态为 pending 或 in_progress。
2. 任一校验不通过返回统一失效结果（不区分原因，4.2.4 规则1）。
3. 校验通过调 F7 StartSession（幂等），任务转进行中。
4. 组装作答上下文返回：任务元信息（test_type、题目数、任务号）、题目全集（按任务题目快照 ID 现读：ai_mgmt 为题号/子能力名/情境/作答要求，enneagram 为题项陈述与作答说明）、已有作答对话记录（重进恢复用，按题号有序）。

#### 5.1.3 涉及数据

| 数据项 | 数据来源 | 数据用途 | 说明 |
|-------|---------|---------|------|
| 链接记录 | F7 assessment_test_links | 令牌校验 | token_hash 点查，valid 状态为可作答前提 |
| 测试任务 | F7 assessment_test_tasks | 任务状态校验与元信息 | pending/in_progress 可作答 |
| 题目快照 | 任务记录 question_ids_json | 取题集合 | 经题目 ID 现读 questions（Unscoped 含软删行，F7 现读口径） |
| 作答对话记录 | 本 feature 新建 | 断点恢复 | 已有回复按题号有序返回 |

#### 5.1.4 业务规则

- **规则1：**令牌校验与数据组装只读不落库（StartSession 幂等推进除外），重进任意次无副作用。
- **规则2：**作答页接口挂公开路由组（非 JWT 鉴权组），令牌自证鉴权；接口限流按 IP 收敛防令牌爆破（复用平台限流中间件，阈值实现期定）。

#### 5.1.5 异常处理

| 异常场景 | 处理方式 | 错误提示/日志 |
|---------|---------|--------------|
| 令牌非法/链接失效/任务不可作答 | 返回统一失效结果 | 页面转失效态；WARN 日志记令牌摘要（不记全文） |
| 会话上报失败（StartSession 推进失败） | 返回通用错误，阻断作答（作答未开始，无半开状态：会话未建立则对话不启动，避免作答中任务停留待作答被逾期判定命中） | ERROR 日志记任务号；页面呈现加载失败与重试，重试重新走校验与上报 |
| 题目现读失败（快照题目被物理删除等异常） | 返回通用错误 | ERROR 日志记任务号；页面呈现加载失败与重试 |

#### 5.1.6 与其他功能的关联

- **上游依赖：**F7（P2_TST_001）链接与任务数据、StartSession 契约；题目数据经 F7 快照现读。
- **下游影响：**作答上下文驱动作答页三态呈现。

### 5.2 作答回复接收（逐题落库）

#### 5.2.1 功能概述

**触发方式：**API 调用（作答页发送回复）
**触发时机：**员工每次发送回复
**功能职责：**校验回复合法性、落库作答对话记录、返回推进指令（下一题包装文案或重答提示或完成态）。

#### 5.2.2 处理流程

1. 接收令牌与回复内容，校验令牌可作答性（同 5.1.2 步骤1；作答中被取消的任务在此被拦，4.1.4 规则5）。
2. 校验回复格式：非空（去首尾空格）；ai_mgmt 长度 ≤500 字符；enneagram 为 1-5 整数。
3. 格式不通过返回重答指令（AI 剧本文案，不落库）；格式通过落库对话记录（题号、回复内容、时间）。
4. 返回推进指令：下一题的剧本包装（题号+题目全文）、或题间确认+下一题、或完成待提交态提示。

#### 5.2.3 涉及数据

| 数据项 | 数据来源 | 数据用途 | 说明 |
|-------|---------|---------|------|
| 作答对话记录 | 本 feature 新建 | 逐条落库 | 一行一回复，阅卷输入载体 |
| 题目全集 | 任务快照现读 | 推进指令组装 | 服务端按已落库记录推算当前题，客户端题号仅作展示 |

#### 5.2.4 业务规则

- **规则1：**服务端为进度权威：当前题号由已落库记录数推算，客户端传入的题号仅作展示，不一致时不拒绝请求，忽略客户端题号、按服务端推算落当前题（跳题、重答已答题一律如此），并在响应中回传实际题号供前端对齐。
- **规则2：**九型非法回复（非 1-5 整数）不落库不推进，返回重答提示（原型同构：AI 提示后停留本题）。
- **规则3：**对话记录只增不改：已落库回复无任何修改、删除路径（员工重进也从断点续，无回改上一题能力，与原型行为一致）。

#### 5.2.5 异常处理

| 异常场景 | 处理方式 | 错误提示/日志 |
|---------|---------|--------------|
| 令牌失效（作答中被取消/链接被重发作废） | 返回失效结果 | 页面转失效态；WARN 日志 |
| 落库失败 | 返回通用错误，前端保留输入内容 | ERROR 日志；员工重试发送 |
| 回复超长（ai_mgmt >500 字符） | 返回格式错误 | 前端输入框字数提示（提交前拦截）+服务端兜底校验 |

#### 5.2.6 与其他功能的关联

- **上游依赖：**5.1 的令牌校验通道复用。
- **下游影响：**对话记录累积驱动完成态；提交后记录成为 F7 阅卷输入。

### 5.3 作答提交（作答数据接收）

#### 5.3.1 功能概述

**触发方式：**API 调用（作答页提交并结束）
**触发时机：**员工完成全部题目后点击提交
**功能职责：**驱动任务完成与阅卷投递（作答记录已逐题落库，提交无终态化动作，5.3.4 规则3；PRD 4.14 作答提交接口：作答数据接收）。

#### 5.3.2 处理流程

1. 接收令牌，校验令牌可作答性与作答完整性（已落库回复数 = 题目总数）。
2. 单事务执行：调 F7 CompleteTask 契约（任务 completed、链接 used、grading_status 置 grading 并投递 assessment:test-grade 任务，投递失败整体回滚）。
3. 返回提交结果（任务号），页面转成功态。

#### 5.3.3 涉及数据

| 数据项 | 数据来源 | 数据用途 | 说明 |
|-------|---------|---------|------|
| 作答对话记录 | 本 feature | 完整性校验 | 已落库记录数为提交门槛 |
| 测试任务/链接 | F7（CompleteTask 事务内推进） | 状态终态化 | 契约单点归属 F7，本功能只调用 |
| 阅卷任务投递 | F7（CompleteTask 事务内 enqueue） | 阅卷触发 | 投递失败整体回滚 |

#### 5.3.4 业务规则

- **规则1：**完整性门槛：题目总数按任务快照计数，未答完不允许提交（前端完成态才出现提交按钮，服务端二次校验兜底）。
- **规则2：**提交幂等：重复提交被 F7 终态守卫拦截（completed/canceled 拦截），拦截时若任务已 completed 仍返回成功结果（页面转成功态），保持员工视角一致。
- **规则3：**作答记录在提交时无额外终态化动作（逐题落库已是终态形态，提交只驱动任务侧状态）。

#### 5.3.5 异常处理

| 异常场景 | 处理方式 | 错误提示/日志 |
|---------|---------|--------------|
| 提交时令牌失效 | 返回失效结果 | 页面转失效态；WARN 日志 |
| 完整性校验失败（记录数 < 题目数） | 返回业务错误 | 提示「存在未作答题目」；页面回到作答态断点 |
| 事务失败（含阅卷投递失败） | 整体回滚，返回通用错误 | ERROR 日志；员工重试提交 |
| 阅卷后续失败 | 归 F7 兜底（重试耗尽降级） | 本功能无感知；任务号供对账 |

#### 5.3.6 与其他功能的关联

- **上游依赖：**F7 CompleteTask 契约（事务内三步推进+阅卷投递）。
- **下游影响：**阅卷引擎消费对话记录评分（F7 grading）；评分汇入画像（F9 消费）。

## 6. 数据状态定义

### 6.1 数据状态

本功能不新增独立状态机：任务状态、链接状态、阅卷状态沿用 F7（P2_TST_001）第 6 章定义，本功能是其员工侧触发方。

**作答页页面形态（呈现态，非持久化状态）：**

| 形态 | 形态说明 | 可转到的形态 |
|------|---------|-------------|
| 作答态 | 令牌有效、任务待作答或进行中，对话施测中（完成待提交态为作答态的末段子阶段，仅输入区转为提示与提交按钮，非独立形态） | 成功态（提交成功）、失效态（令牌失效） |
| 失效态 | 令牌不可作答，统一文案呈现 | 无（终态呈现） |
| 成功态 | 提交成功的结果确认 | 无（终态呈现） |

**作答对话记录（本 feature 新建数据）：**

| 状态名称 | 状态说明 | 可转换到的状态 |
|---------|---------|--------------|
| 已落库 | 员工一条合法回复持久化，随对话累积 | 无（只增不改，提交后随任务阅卷消费） |

### 6.2 状态转换规则

**本功能触发的 F7 状态转换（员工侧触发方，转换语义与守卫归 F7）：**

| F7 当前状态 | 可转换到的状态 | 转换条件 | 转换触发方式 |
|---------|------------|---------|-------------|
| 待作答 | 进行中 | 员工打开链接令牌校验通过（StartSession） | 系统自动（5.1） |
| 进行中 | 已完成 | 员工作答完成提交（CompleteTask） | 系统自动（5.3） |
| 链接有效 | 已使用 | 员工提交作答（CompleteTask 事务内） | 系统自动（5.3） |
| 阅卷待阅卷 | 阅卷中 | 提交事务内投递阅卷任务 | 系统自动（5.3） |

**说明：**本功能仅触发上述四条转换，任务取消、逾期、重发等转换的触发方为 F7 运营侧与逾期 tick。进行中任务到期顺延（F7 5.3.4 规则1）依赖 5.1 会话上报先行，两者口径已对齐。
