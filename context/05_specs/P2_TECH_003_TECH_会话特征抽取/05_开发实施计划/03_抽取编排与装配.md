# 抽取编排与装配 实现计划

> **目标：** 实现抽取编排闭环：ShouldSkip 短会话过滤四条判定、LLM 段两段合成（prompt 模板 + schema 校验 + 一次重试）、Extract 全流程状态机（复用/降级/三态落库）、ExtractByKey 详情拉取封装、Asynq 任务注册与 Wire 装配。
> **架构：** Extractor 依赖五注入点（llm.Client、详情拉取器、档案仓储、参数读取器、密钥提供者，03_api_interface.md §2），会话级终态走 Result 字段、基础设施错误走 error 通道，两条通道互斥（03_api_interface.md §4.2）。worker 注册一会话一任务，装配链由 Wire 编排。
> **技术栈：** Go 1.25、Asynq、Wire、encoding/json schema 校验。

    5. LLM 三块过 Redact（输出侧脱敏，Instruction 逐条）；与 Stats 合成 FeatureProfile
    6. 落库 success 行（profile_json 全四块序列化、error_code 空串）→ 返回 {Status:success, Profile}
    7. 落库失败（Save 返回 err）→ error 通道上抛（ErrStoreWrite 语义 wrap），不落行交 Asynq 重试
    8. 日志口径：跳过 INFO、复用 INFO、schema 重试 WARN、LLM 失败与落库失败 ERROR；字段仅 key/tokenName/计数/错误码，禁消息文本与视图内容
