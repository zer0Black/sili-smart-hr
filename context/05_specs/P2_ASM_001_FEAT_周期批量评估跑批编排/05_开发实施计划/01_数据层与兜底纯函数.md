# 数据层与兜底纯函数 实现计划

> **目标：** 落三张批次表（AutoMigrate）与三个仓储，实现 fallback 兜底纯函数（重试器、告警判定、告警写入）与 schedule 纯函数（触发判定、周期窗口推算、下次执行推算、停滞判定），为后续编排引擎与接口提供数据底座。
> **架构：** domain 三模型走 GORM 通用 tag（比例列 double precision 方言例外沿用 aggregate_scores 先例），仓储用双重接口范式（account 样板），计数推进用 SQL 原子自增。fallback 与 schedule 均为无状态纯函数/薄组件，不依赖 LLM 与上游接口，先行交付可独立 TDD。SessionFeatureRepository 扩展一个失败分子统计方法供编排终态时消费。
> **技术栈：** Go 1.25、GORM（多库：SQLite/MySQL/PostgreSQL）、snowflake（应用层主键）、testing（黑盒包内测试）

  - 关键逻辑：

    ```go
    package fallback

    // 常量（03 §4.7）
    const (
        BatchAlertThreshold = 10.00 // 失败人数占比告警阈值，百分比口径 0-100
    )

    // Retry 通用重试器：固定次数、基准倍增退避、每次尝试派生子 ctx。
    // maxAttempts 含首次（如 4 = 首次 + 3 重试）。父 ctx 取消即终止返回 ctx.Err()。
    // 全部尝试失败返回最后一次错误。attempt 1 失败后不等待（首次立即执行）。
    func Retry(ctx context.Context, fn func(ctx context.Context) error, maxAttempts int, baseDelay time.Duration) error

    // BelowAlertThreshold 告警判定纯函数：失败占比 ≤ 10.00 返回 true（未超阈）。
    // totalCount=0 返回 true（无零除路径，防御式）。百分比口径保留两位小数比较。
    func BelowAlertThreshold(failedCount, totalCount int) bool

    // AlertWriter 告警写入组件（依赖注入仓储）。
    type AlertWriter struct { ... }
    func NewAlertWriter(repo repository.AssessmentAlertRepository) *AlertWriter

    // WriteAlert 批次终态超阈时写告警信号：ratio 按百分比两位小数计算。
    // 写入失败仅记 ERROR 日志返回 nil（specs §5.3.5 兜底不再上抛）。
    func (w *AlertWriter) WriteAlert(ctx context.Context, batch *domain.AssessmentBatch) error
    ```
  - 关键逻辑：
    - `Retry` 退避曲线 `baseDelay << (attempt-1)`（30s→60s→120s），等待用可被 ctx 取消的 sleep；测试注入短 delay 验证次数与退避序列。
    - `BelowAlertThreshold` 用 `math.Round(failed/total*10000)/100` 保留两位小数后与 10.00 比较（`<=` 为未超阈）。
    - `WriteAlert` 从 batch 取 failed_count/total_count/batch_no，组装 `domain.AssessmentAlert`（SignaledAt=now UTC）调仓储 UpsertByBatch。
  - 依赖：`context`、`time`、`math`、`log/slog`、`sili-smart-hr/backend/internal/domain`、`sili-smart-hr/backend/internal/repository`

    ```go
    package pipeline

    // TriggerHit 判定触发时刻是否命中：now 的 HH:mm 等于 triggerTime 且今日为触发日
    // （daily→每日、weekly→周日、monthly→当月最后一天）。triggerTime 为 HH:mm 字符串。
    func TriggerHit(now time.Time, period, triggerTime string) bool

    // CurrentPeriodWindow 推算当前周期窗口（specs §5.1.4 规则1）：
    // daily→[当日00:00, 次日00:00)、weekly→[本周一00:00, 下周一00:00)、
    // monthly→[本月1日00:00, 下月1日00:00)。返回 Unix 秒（左闭右开）。
    func CurrentPeriodWindow(now time.Time, period string) (start, end int64)

    // NextTriggerAt 推算下次执行时点（计划卡，03 A3）：由 period + triggerTime 推算，
    // 已过当次则顺延一个周期。返回格式化前的 time.Time（展示格式化归调用方）。
    func NextTriggerAt(now time.Time, period, triggerTime string) (time.Time, error)

    // StalledDeadline 停滞边界（03 §4.5）：daily→+1天、weekly→+7天、monthly→+1日历月。
    func StalledDeadline(triggeredAt time.Time, period string) time.Time

    // IsStalled 停滞判定：status=running 且 now 超过 StalledDeadline。
    func IsStalled(now, triggeredAt time.Time, period, status string) bool
    ```
