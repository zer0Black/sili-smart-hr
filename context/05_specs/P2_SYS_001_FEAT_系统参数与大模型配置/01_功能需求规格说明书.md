# 功能需求规格说明书

## 1. 概述

### 1.1 功能背景

sili-smart-hr 的评估能否按节奏跑起来，取决于两组控制参数。一组是评估周期参数：多久跑一次、什么时点触发、对哪些人跑，它决定对话分析评估的跑批节奏，同时作为使用活跃度的统计范围。另一组是对外对接密钥：平台调用大模型用的 API Key，以及访问 sili-smart-api 会话日志用的集成密钥，两者同属平台对外对接密钥，决定 LLM 调用与会话日志拉取两条通道能否打通。

这两组参数目前以原型 [system-config.html](../../../06_prototype/01_原型/system-config.html) 与 [secret-config.html](../../../06_prototype/01_原型/secret-config.html) 为蓝本，需要一份可运行的功能把它们落到系统里，供运营人员在线维护。密钥安全是贯穿全程的约束：密钥保存后仅以掩码呈现，明文只在临时查看与查看弹窗中短时可见，运营人员可更新与连通验证。

### 1.2 本功能业务目标

1. 提供评估周期参数的在线配置，覆盖周期长度、触发时点、评估对象，配置在下次跑批生效，同时作为使用活跃度的统计范围。
2. 提供大模型清单的全量维护，排他启用唯一模型，平台所有 AI 能力统一调用该模型，模型与密钥增删改可在线完成。模型按服务商区分接入协议，覆盖 OpenAI 兼容系（DeepSeek、OpenAI、智谱 GLM）与 Anthropic 系两类，第三方 OpenAI 兼容或 Anthropic 兼容代理通过自定义 API 地址接入。
3. 把sili-smart-ap日志集成密钥与 LLM 的 API Key 合并到大模型配置页同页统一管理，提供脱敏展示、临时查看、更新与连通验证，不再单设独立集成密钥页。
4. 密钥保存后掩码化、明文不回显到列表，保证对接密钥在配置维护过程中的最小暴露。

## 2. 角色与权限矩阵

> 系统已全量移除角色概念，平台账号统一全权。本功能不设角色区分，所有已登录平台账号共享同一份系统级配置，无行级数据隔离。

| 角色 | 数据范围 | 说明 |
|------|---------|------|

### 2.2 页面访问权限

| 页面名称 | 可访问角色 | 可操作角色 | 字段级权限（如有） |
|---------|----------|----------|------------------|
| 系统参数页 | 已登录平台账号 | 已登录平台账号 | 无 |
| 大模型配置页 | 已登录平台账号 | 已登录平台账号 | 无 |
| 新增/编辑模型弹窗 | 已登录平台账号 | 已登录平台账号 | 无 |
| 查看模型弹窗 | 已登录平台账号 | 已登录平台账号 | 无 |
| 集成密钥更新弹窗 | 已登录平台账号 | 已登录平台账号 | 无 |

### 2.3 接口鉴权矩阵

| 接口用途 | 方法 | 鉴权方式 | 说明 |
|---------|------|---------|------|
| 评估周期配置查询 | GET | JWT | 返回周期长度、触发时点、评估对象 |
| 评估周期配置保存 | PUT | JWT | 保存周期参数，下次跑批生效 |
| 人员列表查询 | GET | JWT | 评估对象指定人员下拉数据源，来源于 sili-smart-api 用户体系 |
| 大模型列表查询 | GET | JWT | 返回模型清单，API Key 掩码 |
| 模型新增 | POST | JWT | 新建模型，首个模型自动启用 |
| 模型编辑 | PUT | JWT | 保存模型属性，API Key 留空不改 |
| 模型删除 | DELETE | JWT | 物理删除，删除启用项自动转启首个剩余 |
| 模型启停（排他） | PUT | JWT | 启用某模型，其余自动停用 |
| 模型详情查询 | GET | JWT | 查看弹窗加载，返回 API Key 明文 |
| 集成密钥查询 | GET | JWT | 返回集成密钥掩码与配置状态 |
| 集成密钥详情查询 | GET | JWT | 临时查看与查看场景返回集成密钥明文 |
| 集成密钥更新 | PUT | JWT | 更新集成密钥值 |
| 连通验证 | POST | JWT | 探活会话日志接口，返回连通结果 |

承载雪花 ID 的字段（模型主键 ID、人员标识）json 序列化带 `,string`，前端类型用 string，避免精度丢失。

**术语区分（防同名歧义）：** 本文档出现两个同名概念，须严格区分。模型主键 ID 指应用层生成的雪花 ID（int64，数据库主键，承载精度风险，需 `,string` 化）；模型 ID 指用户填写的大模型调用参数（文本，如 `deepseek-chat`，不涉及精度）。两者各自独立，字段表中均单列。具体字段定义由下游「接口数据设计」技能落地。

### 3.1 页面清单

| 序号 | 页面名称 | 页面形式 | 职责说明 | 包含功能 |
|-----|---------|---------|---------|---------|

| 2 | 大模型配置页 | 独立页面 | 上区维护大模型清单与排他启用，下区维护sili-smart-ap日志集成密钥 | 模型列表浏览与搜索、模型启停排他、新增/编辑/查看/删除模型入口、集成密钥掩码查看/更新/连通验证 |

### 3.2 页面跳转流程

```
[入口：顶栏「系统配置 → 系统参数」] → [系统参数页] ——保存/恢复默认——→ 留在系统参数页

[入口：顶栏「系统配置 → 大模型配置」] → [大模型配置页]
                                            ↓ 点击「新增模型」/行内「编辑」
                                      [新增/编辑模型弹窗] → 确定后回到配置页
                                            ↓ 点击行内「查看」
                                      [查看模型弹窗] → 「编辑模型」转编辑弹窗 / 关闭
                                            ↓ 点击行内「删除」
                                      [删除二次确认弹窗] → 确认后回到配置页
                                            ↓ 下区「更新」（集成密钥卡片）
                                      [集成密钥更新弹窗] → 确认后回到配置页
                                            ↓ 下区「连通验证」（集成密钥卡片）
                                      [连通验证结果提示] → 留在配置页
```

**流程说明：**
1. 用户从顶栏「系统配置」一级菜单进入「系统参数」或「大模型配置」两个二级页面。
2. 系统参数页为单例表单，配置保存后下次跑批生效，操作完成留在本页。
3. 大模型配置页上区为模型列表，所有模型新增、编辑、查看、删除、启停均通过弹窗或行内操作完成，操作后留在本页；下区为集成密钥卡片，更新经弹窗、连通验证就地反馈。

## 4. 页面功能详细说明

### 4.1 页面 1：系统参数页

#### 4.1.1 页面概述

**页面形式：** 独立页面，挂 `_authenticated` 顶栏「系统配置」一级菜单下的「系统参数」。

**页面职责：** 承载评估周期参数这一系统级单例配置。页面按三个区段组织：周期与触发（周期长度下拉、触发时点时间选择、触发日只读联动、评估区间只读说明）、评估对象（全员或指定人员多选）、成本说明（调用量与节流告示）。所有改动保存后下次跑批生效。

#### 4.1.2 涉及字段

> 本页为单例配置表单，非列表页。字段按区段描述。

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---------|---------|---------|---------|---------|--------|---------|
| 周期长度 | 下拉 | 用户输入 | 用户选择 | 必填，每天/每周/每月三选一 | 每周 | 评估跑批周期，同时作为使用活跃度统计范围 |
| 触发时点 | 时间选择 | 用户输入 | 用户选择 | 必填，HH:mm | 23:00 | 周期结束当天的触发时刻 |
| 触发日（只读） | 文本（只读） | 系统联动 | 周期变更时联动 | 无 | 每周日 | 由周期长度联动：日→每日、周→每周日、月→每月最后一天 |
| 评估区间（只读） | 文本（只读） | 系统计算 | 周期或时点变更时计算 | 无 | 随周期联动 | 只读说明抽取区间规则与示例，区间不重叠不遗漏 |
| 评估对象 | 多选下拉 | 用户输入 | 用户选择 | 必填，全员或指定人员 | 全员 | 跑批评估对象，全员与指定人员互斥 |
| 成本节流告示（只读） | 告示（只读） | 系统计算 | 评估对象变更时计算 | 无 | 随对象联动 | 只读提示当前评估对象人数与节流说明 |

#### 4.1.3 功能与按钮

**用户可操作功能：**

- **保存配置**
  - 触发按钮：保存
  - 按钮级别：页面级
  - 按钮位置：页面底部固定操作区右侧
  - 触发方式：点击按钮
  - 权限要求：已登录平台账号
  - 加载状态：点击后至接口响应完成前 loading，防重复提交
  - 功能说明：提交周期长度、触发时点、评估对象，成功后提示「评估区间配置已保存，将在下次评估生效」，留在本页。

- **恢复默认**
  - 触发按钮：恢复默认
  - 按钮级别：页面级
  - 按钮位置：页面底部固定操作区左侧
  - 触发方式：点击按钮
  - 权限要求：已登录平台账号
  - 加载状态：否
  - 功能说明：将表单回滚到默认值（每周、23:00、全员），不触发接口，提示「已恢复评估区间默认配置」。

#### 4.1.4 业务规则

- **规则1：配置生效时机**
  - 规则描述：周期长度、触发时点、评估对象的保存，均在下次评估跑批时生效。
  - 触发条件：保存配置成功。
  - 约束说明：当前评估区间已启动的跑批不中断，下次跑批按新参数执行；已产出的历史画像不重算。

- **规则2：评估对象互斥**
  - 规则描述：全员与指定人员互斥，同一时刻只能选其一。
  - 触发条件：选择评估对象。
  - 约束说明：选「全员」则清空已选指定人员；选任意指定人员则自动移除「全员」。评估对象不可为空。

- **规则3：周期与触发联动**
  - 规则描述：触发日与评估区间说明由周期长度联动，不可手填。
  - 触发条件：切换周期长度或触发时点。
  - 约束说明：日周期每日触发抽取当日、周周期每周日触发抽取本周一至本周日、月周期每月最后一天触发抽取本月 1 日至月末；区间之间不重叠、不遗漏，保证同一人跨评估区间评分可比。

- **规则4：评估对象数据来源**
  - 规则描述：指定人员下拉数据来源于 sili-smart-api 用户体系的人员标识到人名映射。
  - 触发条件：展开评估对象下拉。
  - 约束说明：首期仅取人名，无部门与组织归属；人员数据接入前可降级为仅全员模式。系统全量无员工编号，人员选项不出现工号。已选指定人员从用户体系消失（离职、删除）时，跑批时自动跳过并记录，不中断评估；配置页下次加载时从已选列表剔除。指定人员下拉加载失败时 toast 提示「人员数据暂不可用，已切换为仅全员模式」，自动选中全员并置灰指定人员选项，重试在下次展开下拉时触发。

- **规则5：操作异常反馈**
  - 规则描述：保存配置按统一策略反馈异常。
  - 触发条件：接口返回失败。
  - 约束说明：网络或服务异常 toast 提示「操作失败，请稍后重试」，允许重试；并发冲突（配置已被他人变更）toast 提示「配置已变更，请刷新后重试」并中止本次提交。

#### 4.1.5 交互逻辑

- 页面加载时拉取当前周期配置回填表单，底部固定操作区左侧提示「配置将在下次评估生效」。
- 评估区间说明以只读信息块呈现规则文案与日期示例，随周期或时点变更实时刷新。
- 成本节流告示随评估对象变更刷新当前评估人数与调用量提示。
- 评估对象下拉支持按人名过滤、折叠标签展示多选值。

#### 4.1.6 权限要求

参见第 2.2 节页面访问权限。本页面无第 2 章未覆盖的特殊权限规则。

### 4.2 页面 2：大模型配置页

#### 4.2.1 页面概述

**页面形式：** 独立页面，挂 `_authenticated` 顶栏「系统配置」一级菜单下的「大模型配置」。页面分上下两区。

**页面职责：** 上区为大模型列表，承载模型 CRUD 与排他启用，列表按模型名称搜索，每行可查看、编辑、删除、切换启用；下区为sili-smart-ap日志集成密钥卡片，承载集成密钥的脱敏展示、临时查看、更新与连通验证。两区合并管理平台两类对外对接密钥，体现排他启用唯一模型、所有 AI 调用走该模型的系统约束。

#### 4.2.2 涉及字段

> 本页上区为列表，下区为单例卡片。字段分查询字段、显示字段、集成密钥卡片字段三组。

##### A. 查询字段（模型列表）

| 字段名称 | 字段类型 | 数据来源 | 默认值 | 业务含义 |
|---------|---------|---------|--------|---------|
| 搜索关键词 | 文本 | 用户输入 | 空 | 按模型名称或模型 ID 模糊过滤模型列表 |

##### B. 显示字段（模型列表）

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 业务含义 |
|---------|---------|---------|---------|---------|
| 模型名称 | 文本 | 数据库查询 | 页面加载 | 模型显示名称，下方副标题展示模型 ID |
| 服务商 | 标签 | 数据库查询 | 页面加载 | 模型接入的服务商 |
| API 地址 | 文本 | 数据库查询 | 页面加载 | 服务商接口地址，留空为默认地址 |
| API Key | 文本（掩码） | 数据库查询 | 页面加载 | 掩码呈现，支持临时查看明文 |
| 启用状态 | 开关 | 数据库查询 | 页面加载 | 排他启用，同时刻仅一个启用 |
| 操作 | 按钮组 | 系统预设 | 页面加载 | 查看、编辑、删除 |

**列表级附属信息：** 列表底部显示模型总数与当前启用模型名称，附说明「平台所有 AI 调用走该模型」（具体位置见 4.2.5 交互逻辑）。

##### C. 集成密钥卡片字段（下区单例）

| 集成密钥 | 文本（掩码） | 数据库查询 | 页面加载 | 访问 sili-smart-api 会话日志的 Bearer 密钥，掩码呈现，支持临时查看；未配置时显示占位文案「未配置」，临时查看禁用 |
| 密钥配置状态 | 标签 | 数据库查询 | 页面加载 | 已配置或未配置 |

#### 4.2.4 业务规则

- **规则1：排他启用唯一模型**
  - 规则描述：同一时刻仅一个模型处于启用态，平台所有 AI 调用统一走该模型。
  - 触发条件：切换启用状态、新增首个模型、删除启用态模型。
  - 约束说明：启用某模型时其余模型自动停用；首个新增模型自动启用；系统无独立默认模型概念，启用即默认。

- **规则2：启用项不可直接关闭**
  - 规则描述：当前启用模型不可通过开关直接关闭，保证始终有一个启用的模型。
  - 触发条件：点击当前启用模型的开关。
  - 约束说明：开关操作被拦截并提示「必须保持一个启用的模型，请先启用其他模型」；停用当前启用模型的唯一路径是启用另一个模型。

- **规则3：删除前置与启用项转启**
  - 规则描述：至少保留一个模型，删除启用态模型时自动转启首个剩余模型。
  - 触发条件：点击删除模型并经二次确认。
  - 约束说明：模型清单仅剩一个时删除被拦截并提示「至少保留一个模型」；删除启用态模型时，剩余模型按列表顺序取首个自动启用，并提示转启结果。模型删除为物理删除，删除后无法恢复。

- **规则4：密钥掩码化**
  - 规则描述：API Key 与集成密钥保存后列表与卡片仅以掩码呈现，明文不在列表回显。
  - 触发条件：模型或集成密钥保存成功后加载列表与卡片。
  - 约束说明：掩码保留密钥前缀与末四位、中段以星号替代；明文仅在临时查看与查看弹窗中短时可见，临时查看刷新后恢复掩码。

- **规则5：连通验证范围**
  - 规则描述：连通验证只覆盖sili-smart-ap日志集成密钥对 sili-smart-api 会话日志接口的探活。
  - 触发条件：点击连通验证。
  - 约束说明：LLM 模型的连通性在评估引擎实际调用时校验，配置页不对 LLM 模型强制连通验证；集成密钥未配置时不允许连通验证，提示先配置密钥。

- **规则6：操作异常反馈**
  - 规则描述：本页与各弹窗的写操作（新增、编辑、删除、启停、更新、连通验证）按统一策略反馈异常。
  - 触发条件：接口返回失败。
  - 约束说明：表单校验失败时字段内联报错并保留已填输入，不关闭弹窗；网络或服务异常 toast 提示「操作失败，请稍后重试」；连通验证失败就地提示失败原因。

- **规则7：服务商与接入协议映射**
  - 规则描述：模型按服务商区分接入协议，DeepSeek、OpenAI、智谱 GLM 走 OpenAI 兼容协议，Anthropic 走 Anthropic 协议；第三方代理按所选服务商归属协议调用。
  - 触发条件：选择服务商提交模型。
  - 约束说明：配置层只承载服务商、API 地址、API Key，不感知协议的请求结构与鉴权头差异，协议适配由下游 LLM 调用底座按服务商归属协议执行；API 地址留空走服务商默认地址，填写则覆盖为代理地址。

#### 4.2.5 交互逻辑

- 模型列表不分页，底部显示模型总数与当前启用模型名称，附说明「平台所有 AI 调用走该模型」。

## 6. 数据状态定义

### 6.1 数据状态

| 状态名称 | 状态说明 | 可转换到的状态 |
|---------|---------|--------------|
| 启用（模型） | 当前排他启用，平台所有 AI 调用走该模型 | 停用 |
| 停用（模型） | 模型保留但不启用，可编辑、删除、再启用 | 启用、已删除 |
| 已删除（模型） | 物理删除，模型从清单移除，无法恢复 | 无（终态） |
| 已配置（集成密钥） | 集成密钥已保存，可连通验证、更新 | 已配置（更新覆盖，保留为后续能力） |
| 未配置（集成密钥） | 集成密钥为空，会话日志拉取不可用 | 已配置 |

### 6.2 状态转换规则

| 当前状态 | 可转换到的状态 | 转换条件 | 转换触发方式 |
|---------|------------|---------|-------------|
| 启用 | 停用 | 启用另一个模型，原启用项自动停用 | 用户操作 |
| 停用 | 启用 | 切换该模型启用状态开关，其余自动停用 | 用户操作 |
| 停用 | 已删除 | 点击删除并经二次确认 | 用户操作 |
| 启用 | 已删除 | 点击删除并经二次确认，剩余首个模型自动转启 | 用户操作 |
| 已配置 | 已配置 | 更新提交新密钥覆盖旧密钥 | 用户操作 |
| 未配置 | 已配置 | 更新或首次配置提交新密钥 | 用户操作 |

## 8. 附录

### 8.1 术语表

| 术语 | 定义 | 说明 |
|------|------|------|
| 评估周期参数 | 系统参数页配置的参数组统称 | 包含周期长度、触发时点、评估对象三项，是配置层的整体概念 |
| 周期长度 | 评估跑批的字段级粒度 | 具体字段，每天/每周/每月三选一，决定跑批节奏 |
| 跑批周期 | 评估跑批执行的节奏 | 由周期长度决定，如每周跑一次，是运行时概念 |
| 评估区间 | 跑批抽取对话数据的时间范围 | 由周期长度与触发时点联动得出，如周周期为周一至周日，区间不重叠不遗漏，同时作为使用活跃度统计范围 |
| 排他启用 | 同一时刻仅一个模型启用 | 启用某模型则其余自动停用，平台所有 AI 调用走该模型 |
| 接入协议 | 大模型调用遵循的请求与鉴权规范 | 由服务商决定：DeepSeek、OpenAI、智谱 GLM 走 OpenAI 兼容协议，Anthropic 走 Anthropic 协议；协议适配在下游 LLM 调用底座执行 |
| 模型主键 ID | 模型记录的雪花主键 | 应用层生成的 int64，承载精度风险，json 序列化须带 `,string` |
| 模型 ID | 大模型调用参数 | 用户填写，传入服务商的 model 参数，如 `deepseek-chat`，文本类型，不涉及精度 |
| API Key | 大模型服务商的调用密钥 | 在服务商后台获取，保存后掩码显示 |
| 集成密钥 | 访问 sili-smart-api 会话日志的 Bearer 密钥 | 与 API Key 同属平台对外对接密钥，同页管理 |
| 连通验证 | 用集成密钥探活会话日志接口 | 确认密钥有效与接口可达，配置页只覆盖集成密钥 |
| 更新密钥 | 覆盖写入新的密钥值 | 密钥到期或泄露时用新值覆盖旧值，旧密钥立即失效；信息安全领域称「密钥轮换」（key rotation），面向运营人员的产品文案统一用「更新」 |

### 8.3 通用交互与UI规范

全系统级别的UI和交互约定详见：[01_通用需求.md](../01_通用需求.md)

**偏离记录：**
- 模型列表不分页（通用规范：所有列表分页）。模型数量通常为个位数，底部仅显示总数与当前启用模型，不加分页器。
- 模型删除为物理删除（通用规范：删除软删除+二次确认）。模型删除保留二次确认弹窗，但删除为物理删除、删除后无法恢复。

说明：模型名称上限 50 字符、API 地址 URL 格式、模型 ID 与密钥类字段长度为功能特有规则；评估周期与人员数量为整数，不适用通用「数字精确到小数点后两位」（该规范针对金额类数值）。
