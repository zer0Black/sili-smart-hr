# 裁剪与统计 实现计划

> **目标：** 实现 extractor 的纯规则裁剪内核：消息三分类（噪音丢弃/规约指纹/保留）、提取通道（command-args、system 插话、打断标记、内嵌 SR 剥离）、TrimmedView 组装与预算截断、ProfileStats 统计块（含粘贴判定、指令规范化哈希）与 Redact 脱敏，全部纯函数不调 LLM 不落库。
> **架构：** 单遍消息扫描，分类器输出逐消息处置决策（丢弃/指纹/事件/保留行），Trim 组装视图行并执行截断，统计块与裁剪同遍计算。前缀黑名单经 SystemParamReader 注入可热调，默认取包内常量。
> **技术栈：** Go 1.25 纯标准库（strings/regexp/crypto/sha256/sort）。
