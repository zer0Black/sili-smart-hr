# 登录安全 实现计划

> **目标：** 把登录链路规格化为 RSA-OAEP 密文传输，补齐反枚举的 RSA 解密失败路径，落地公钥接口限流与登录双维度（IP + username）限流，前端登录页改为加密提交。
> **架构：** 后端新增 rsakey 包管理动态密钥对（私钥 Redis 一次性缓存），account service 注入 PasswordDecryptor 接口使登录先解密再 bcrypt；公钥接口挂公开组并加 Redis 固定窗口 IP 限流；登录路由叠加 IP 限流（中间件层）与 username 维度限流（handler 层，绑定 body 后计数）作为反枚举辅助；前端引入 node-forge 做 RSA-OAEP 加密，登录页加载即取公钥。
> **技术栈：** Go crypto/rsa + go-redis v9 + miniredis（测试）；前端 node-forge + TanStack Query。

  **契约：**

  - import：`crypto/rsa`、`crypto/rand`、`crypto/x509`、`crypto/sha256`、`encoding/pem`、`encoding/base64`、`encoding/hex`、`context`、`errors`、`time`、`github.com/redis/go-redis/v9`
  - 签名：
    - `const keyPrefix = "sili-smart-hr:auth:rsa:"`
    - `var ErrKeyNotFound = errors.New("rsakey: key not found or expired")`
    - `type Manager struct { rdb *redis.Client; ttl time.Duration }`
    - `func NewManager(rdb *redis.Client, ttl time.Duration) *Manager`
    - `func (m *Manager) Generate(ctx context.Context) (publicKeyPEM string, keyID string, err error)`：生成 2048 位 RSA 密钥对（rsa.GenerateKey(rand.Reader, 2048)）；keyID = 16 字节随机（crypto/rand）转 32 字符 hex；私钥 x509.MarshalPKCS8PrivateKey 后 PEM 编码（PKCS#8）；`rdb.Set(ctx, keyPrefix+keyID, privPEM, m.ttl)`；公钥转 x509.MarshalPKCSIXPublicKey 后 PEM（SubjectPublicKeyInfo）返回。
    - `func (m *Manager) Decrypt(ctx context.Context, keyID string, ciphertextB64 string) (plaintext string, err error)`：`rdb.GetDel(ctx, keyPrefix+keyID)`（go-redis v9 支持 GetDel，一次性）；Val 为空返 ErrKeyNotFound；PEM 解码为 *rsa.PrivateKey；base64.StdEncoding.DecodeString 解密文；`rsa.DecryptOAEP(sha256.New(), rand.Reader, priv, cipherBytes, nil)`；返回明文。解密失败分支也尝试 Del 该 key 防残留。
  - 关键逻辑：OAEP 填充用 SHA-256；GETDEL 保证私钥一次性（解密成功即删）；TTL 由构造方传入（登录场景 5 分钟）。
