# 注册表与规则迁移 实现计划

> **目标：** 建立 extractor/rules 子包：registry 注册表、generic 通用规则层、五个客户端规则文件，把基线 injectPrefixesFactory/assistantPrefixesFactory 平面集合按形态归属拆分为各客户端 UserPrefixes/NonUserPrefixes，InjectPrefixes 改为并集组装器。判定链行为与落库零变化（classify.go 仅换前缀集来源引用点，见 T6），编译安全。
> **架构：** rules 包自足（ClientRules 接口与七值常量定义在包内），extractor → rules 单向依赖。前缀字面从 config.go 平面变量按形态归属（基线分组注释仅参考）迁移到各客户端文件，config.go 保留组装器与脱敏正则。等集关系由注册表完备性测试守护（快照锚定集）。
> **技术栈：** Go 1.25，标准库 slices/strings，无新依赖。

  **契约：**
  - 签名：

    ```go
    package rules

    // 客户端标识常量（七值单源，specs §2.3 值域；mixed/unknown 是探测裁决值非规则归属）
    const (
        ClientClaudeCode = "claude_code"
        ClientOpenCode   = "opencode"
        ClientWorkBuddy  = "workbuddy"
        ClientOMO        = "omo"
        ClientAutomation = "automation"
        ClientMixed      = "mixed"
        ClientUnknown    = "unknown"
    )

    type ClientRules interface {
        Client() string
        UserPrefixes() []string
        NonUserPrefixes() []string
        DetectFeatures() []DetectFeature
    }

    type DetectFeature struct {
        Kind    string // "prefix" | "marker"
        Pattern string
        Weight  int  // ≥1；专属强特征 2-3、共享形态 1
        Once    bool // true 全会话命中一次即计
    }

    func Register(r ClientRules)
    func AllClientRules() []ClientRules
    ```

  - 依赖：仅标准库，无 import。
