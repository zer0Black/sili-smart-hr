# 团队看板 后端数据域 实现计划

> **目标：** 交付团队看板的全部后端能力：team_training_suggestions 建表、A1/A2 两个只读聚合查询接口、建议生成两段式 Asynq 任务（tick 拾取 + LLM 生成落库）、errcode/wire/router/mux 装配全链路。
> **架构：** 沿 account 全链路样板（domain → repository → service → handler → router → wire），dashboard 为纯新增域（service/dashboard.go、handler/dashboard.go），聚合实时计算不落库只读消费既有七表；建议生成循 batch-tick → batch-run 先例拆 suggest-tick（扫描拾取，生成中行即锁）+ suggest-generate（素材汇总调 LLM 脱敏落库）两段，引擎逻辑独立 internal/engine/suggestgen 包，LLM 走专用 client（180s，独立并发 gate）。
> **技术栈：** Go 1.25、Gin、GORM（三库兼容）、Asynq、Wire、slog。
