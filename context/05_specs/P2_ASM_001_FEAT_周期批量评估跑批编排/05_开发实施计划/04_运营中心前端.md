# 运营中心前端 实现计划

> **目标：** 建评测运营中心页（tab 容器首期一个 tab）：态势统计卡、跑批计划卡、批次列表（筛选 + 10 秒轮询 + 停滞标识）、发起评测弹窗（人员选择 + 时段默认回填 + 全员互斥）、失败明细弹窗（只读清单 + 补跑预填），顶栏导航接通。
> **架构：** 新建 assessment feature 三件套（api/hooks/types）+ components，路由挂 `_authenticated/assessment/index.tsx`，导航 leaf 接通。日期范围选择用两个原生 `<input type="date">`（项目无日期范围选择器组件依赖，YAGNI 不引入；日期运算用既有 dayjs）。人员选择组件不复用 system-params 的 MemberMultiSelect（降级行为相反：本页失败保留重试通道），新建发起弹窗专用组件。
> **技术栈：** React 19 + TypeScript、TanStack Query（10s refetchInterval 轮询）、react-hook-form + zod（发起表单）、shadcn/ui（dialog/badge/table/select/card）、i18next（新 ns assessment）
