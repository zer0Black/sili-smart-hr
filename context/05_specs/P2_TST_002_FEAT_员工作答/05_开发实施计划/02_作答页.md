# 作答页 实现计划

> **目标：** 把 /answer/$token 占位页替换为完整对话式作答页：三态路由（作答/失效/成功）、品牌头与 hero 元信息、AI 对话区逐题推进、断点恢复、提交闭环。
> **架构：** 路由文件只做入口，页面实现下沉 features/answer 新域（api/hooks/components 三件套 + 消息流纯函数）。作答页用独立 axios 实例（不读 auth store、不触发 401 登出），剧本文案全部走 i18n answer 命名空间（03 §1.4 前后端分工：服务端只发推进事实，前端渲染剧本）。
> **技术栈：** React 19 + TypeScript + TanStack Router 文件路由 + TanStack Query（仅提交/回复 mutation，上下文一次性加载不走轮询）+ axios 独立实例 + i18next + Tailwind 4 token + shadcn/ui 原子件。

    ```ts
    export function applyReplySuccess(t: TFunction, prev: ScriptState, ctx: AnswerContextResult, reply: AnswerReplyResult): ScriptState;
    // 本地校验（发送前拦截，specs §5.2.5）：enneagram 非 1-5 整数返 false；ai_mgmt 空串返 false
    export function isValidLocalInput(testType: AnswerTestType, content: string): boolean;
    // 进度百分比（specs §4.1.2 B 对话进度）
    export function progressPercent(answered: number, total: number): number;

    // answer-hooks.ts
    export function useAnswerContext(token: string): UseQueryResult<AnswerContextResult, AnswerApiError>;
    export function useAnswerReply(token: string): UseMutationResult<AnswerReplyResult, AnswerApiError, { content: string; questionSeq: number }>;
    export function useAnswerSubmit(token: string): UseMutationResult<AnswerSubmitResult, AnswerApiError, void>;
    ```
  - 关键逻辑：
    - buildInitialMessages：t 取剧本 key；开场白两段（按 test_type）→ 逐条回放 replies（user 消息）与对应题目（replies[i].seq 题的 AI 包装消息，间插题间确认）→ 末尾当前题：answered < total 时当前题（seq=answered+1） asking 态；ctx.finished 时完成提示两段 + phase='finished'（specs §4.1.3 对话恢复：进度与当前题从记录推算）。
    - applyReplySuccess：push user 消息 → action=next 时题间确认 + next_question 包装消息（题号行/情境段/作答要求段多段 lines，原型同构）；action=finished 时完成提示两段并置 phase='finished'。
    - isValidLocalInput：ai_mgmt 仅判 trim 非空（500 上限经字数计数器预拦 + maxLength）；enneagram 用 /^[1-5]$/ 全匹配。
    - AnswerChat 组件：消息流滚动容器自动滚底（useEffect + scrollTop）；发送中显示三点 typing 气泡并禁用输入区；ai_mgmt 输入框带 500 字符计数器；回车发送 Shift+回车换行；phase='finished' 输入区原位替换为完成提示文案与「提交并结束」按钮（loading 至响应）。1902 错误：AI 剧本提示 invalidReply 消息追加、输入框保留员工输入（specs §4.1.5）；1903（提交未答完）：toast 提示后停留作答态；1500/网络错误：保留输入可重试。submit 成功回调经 AnswerPage 转 success 态（任务号取 mutation 返回 task_no）。
    - 服务端 QuestionSeq 回传对齐：reply 响应 question_seq 与本地不一致时以服务端数据重建当前题（specs §5.2.4 规则1 前端对齐义务）。
