# 档案组装与评估 实现计划

> **目标：** 实现 evaluator 的档案集分层组装（能力2）与跨会话综合评估（能力1）：ProfileDigest 消费、密度排序与预算截取、五段 prompt 组装、LLM 调用与 schema 校验收敛、评分行落库（含幂等判定、failed 翻转、零档案跳过、Redact 兜底脱敏）。
> **架构：** evaluator 包内文件按职责分立：types.go（常量与口径类型）、digest.go（档案取数与归一，复用 activity.ParseDigests）、assemble.go（两层组装与密度排序）、prompt.go（五段模板常量与组装函数）、schema.go（宽容解析与校验）、evaluate.go（主流程与落库）。LLM 经评估专用 client（03 §2.1，Wire 装配归 03 子计划）；评分行落库走 DimensionScoreRepository（01 子计划已交付）。档案取数的 24h 缓冲加末轮过滤与 activity 侧同口径，单点收敛在 evaluator 包内（两侧各自调 ListByPersonAndRange 后共用归一谓词语义）。
> **技术栈：** Go 1.25、encoding/json（宽容解析同 T4 schema.go）、slog。
