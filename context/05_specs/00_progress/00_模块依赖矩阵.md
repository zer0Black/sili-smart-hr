# 模块依赖矩阵

## 模块代号注册表

| 模块代号 | 模块名称 | 分类 | 说明 |
|----------|---------|------|------|
| USR | 用户管理 | 业务 | 用户注册、登录、个人信息 |
| ORD | 订单管理 | 业务 | 订单创建、查询、状态流转 |
| PAY | 支付管理 | 业务 | 支付、退款、账单 |
| ACC | 账号与认证 | 业务 | 登录认证、账号台账 |
| SYS | 系统初始化与参数 | 业务 | 首访向导、系统参数、评估周期、大模型与密钥配置 |
| DIM | 维度与权重配置 | 业务 | 能力模型维度、权重与活跃度阈值 |
| QBN | 题库管理 | 业务 | 题目生成、量表引入、审核与维护 |
| ASM | 评估跑批编排 | 业务 | 周期批量评估与失败兜底 |
| TST | 主动测试运营 | 业务 | 测试发起、阅卷与生命周期管理 |
| PRF | 个人画像 | 业务 | 画像查询、画像详情只读消费 |
| TMD | 团队看板 | 业务 | 团队聚合看板、逐期趋势、培训建议生成 |
| WRK | 工作台 | 业务 | 总览入口与待办中枢：评估态势、待处理项、需关注人群、团队画像速览 |
| LOG | 操作日志 | 业务 | 操作审计：记录通道（中间件兜底+关键域埋点）、批次级节点、查询与导出、定期清理 |
| TECH | 通用技术能力 | 技术 | 文件上传等技术组件 |

> 注册规则：2-4位大写字母，语义清晰。新代号必须在此注册。分类为"技术"的模块代号对应的 feature 视为技术组件，否则视为业务功能。下游技能（fm、监理、开发计划等）的类型推断统一读此注册表的分类列，不再硬编码判断。
