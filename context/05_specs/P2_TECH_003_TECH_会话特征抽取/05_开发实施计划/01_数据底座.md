# 数据底座 实现计划

> **目标：** 落地 session_features 与 system_params 两张表（domain 模型 + AutoMigrate + 参数出厂 seed），实现 SessionFeatureRepository 幂等状态机与 SystemParamReader 键缺失回退读取，为后续裁剪与抽取子计划提供持久化底座。

> **技术栈：** Go 1.25、GORM v2（多库兼容 tag）、雪花 ID 应用层生成。

    // SessionFeatureRepository 是特征档案的数据访问接口（双重接口范式，account 样板）。
    type SessionFeatureRepository interface {
        // FindBySessionKey 按 session_key 点查既有行（幂等预检用）。
        // 无行返回 (nil, nil)，调用方据 nil 判定首次写入。
        FindBySessionKey(ctx context.Context, sessionKey string) (*domain.SessionFeature, error)
        // Save 幂等落库：已存在 success 行返回 reused=true 不覆盖；failed 允许原地翻转 success；
        // skipped 行为终态（再次写入返回 reused=true）。唯一索引 uk_session_key 兜底并发双写
        //（冲突转重查收敛）。
        Save(rec *domain.SessionFeature) (reused bool, err error)
        // ListByPersonAndRange 按人加时间窗取档案（T5 evaluator 取数口径）。
        // start/end 为 Unix 秒，仓储内转 time.Time 走 idx_token_first_turn 组合索引；
        // 返回全部三态行。
        ListByPersonAndRange(tokenName string, start, end int64) ([]domain.SessionFeature, error)
    }
    func NewSessionFeatureRepository(db *gorm.DB) SessionFeatureRepository
    ```
  - 关键逻辑：Save 前按 session_key 点查。无行 insert（显式置雪花 ID 由全局回调赋值，业务层显式置所有字符串列非空值）；已有 success 行直接返回 reused=true；已有 failed 行且新 rec.Status=success 时 UPDATE 同一行（保留原 ID，刷新 updated_at）；已有 skipped 行返回 reused=true 不动；新 rec.Status=failed 且已有 failed 行时 UPDATE 覆盖（重试仍失败刷新 error_code）；insert 时撞 uk_session_key 唯一索引冲突（GORM ErrDuplicatedKey 类错误）转重查一次收敛为 reused。ListByPersonAndRange 用 `time.Unix(start,0)`/`time.Unix(end,0)` 构造区间 `first_turn_at >= ? AND first_turn_at <= ?`，按 first_turn_at 升序
  - 边界：并发双写兜底靠唯一索引（04 §3.1 索引说明）；区间端点闭区间含边界

  **验收锚点：**
  - 核心断言：`TestSaveIdempotentStateMachine` 四分支：首写 success 后再 Save 同 key 返回 reused=true 且 DB 行不变；failed 行翻转 success 后 status=success 且 LLM 三块补齐（profile_json 非空）；skipped 行再 Save 返回 reused=true 不变；同 key 两次 failed Save 第二次 UPDATE 不产生新行（表行数=1）

  - `TestFindBySessionKey`：预置行后点查返回该行；查不存在 key 返回 (nil, nil) 而非 error
  - 验证命令：`cd hr-backend && go test ./internal/repository/ -run 'TestSaveIdempotent|TestListByPerson' -v`

    type SystemParamReader interface {
        // ReadStringArray 按键读字符串数组参数。行不存在或值反序列化失败时返回
        // 出厂默认（由调用方以 extractor 包常量注入），DB 非唯一权威。
        ReadStringArray(key string) ([]string, error)
    }
    // NewSystemParamReader 构造，defaulter 提供键缺失/损坏时的回退值。
    // defaulter 形如 map[string][]string{"extractor.inject_prefixes": extractor.InjectPrefixes, ...}
    // 由装配层构造注入（providers.go，T12）。
    func NewSystemParamReader(db *gorm.DB, defaulter map[string][]string) SystemParamReader
    ```
  - 关键逻辑：按 param_key 点查（uk_param_key）；行存在且 json.Unmarshal 成功返回解析值；行不存在（ErrRecordNotFound）或反序列化失败返回 defaulter[key]（key 无映射时返回空切片），反序列化失败记 WARN 日志但 error 返回 nil（回退即正常路径，04 §3.2 键缺失回退）。error 仅在真实 DB 故障时非 nil。键语义边界：extractor.inject_prefixes 空数组=黑名单清空放开过滤（业务放开）；extractor.redact_patterns 空数组在 Redact 侧恒回退出厂集（安全兜底，见子计划 02 T4），读取层不做特判原样返回
  - 边界：空数组 param_value（`[]`）合法返回空切片（黑名单清空回退 role 兜底全保留口径，04 §3.2 值格式约定）

  **验收锚点：**
  - 核心断言：`TestReadStringArray` 三分支：预置行返回解析值；行不存在返回 defaulter 值；预置损坏 JSON（`{bad`）返回 defaulter 值且 err=nil；`TestReadStringArrayEmptyArray`：param_value=`[]` 返回空切片非 nil
