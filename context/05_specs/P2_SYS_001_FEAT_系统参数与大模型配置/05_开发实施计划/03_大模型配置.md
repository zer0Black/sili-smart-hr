# 大模型配置 实现计划

> **目标：** 实现大模型配置页上区全链路，包括模型列表查询（B1）、新增（B2）、编辑（B3）、删除（B4）、启用排他（B5）、详情查看（B6）六个后端接口，以及前端模型列表、搜索、新增/编辑模型弹窗、查看模型弹窗、删除二次确认、排他启用开关。
> **架构：** 后端按 account 四层样板新增 llm config 的 repository → service → handler，service 层用事务保证排他启用与删除转启的全表唯一 enabled 约束，密钥经 RSA 解密后 AES-256-GCM 加密落库并刷新掩码快照；前端新增 system/llm 路由页与 feature，列表掩码展示、弹窗表单 RHF + Zod + RSA 加密传输 api_key。
> **技术栈：** Go 1.25（GORM 事务）、React 19 + RHF + Zod + RSA-OAEP（复用 lib/crypto.ts）。

  ```go
  type LLMConfigRepository interface {
      List(ctx context.Context, keyword string) ([]domain.LLMConfig, error)  // 全量，keyword 按名称或 model_id 模糊
      FindByID(ctx context.Context, id int64) (*domain.LLMConfig, error)
      Create(ctx context.Context, cfg *domain.LLMConfig) error
      Update(ctx context.Context, cfg *domain.LLMConfig) error  // 整行属性保存
      Delete(ctx context.Context, id int64) error
      Count(ctx context.Context) (int64, error)
      FindFirstEnabled(ctx context.Context) (*domain.LLMConfig, error)  // 当前启用项
      FindFirstByIDOrder(ctx context.Context, excludeID int64) (*domain.LLMConfig, error)  // 删除转启用：按列表顺序取首个剩余（排除被删 id）
      EnableExclusive(ctx context.Context, id int64) error  // 事务内其余置 false、目标置 true
  }

  type llmConfigRepository struct { db *gorm.DB }
  func NewLLMConfigRepository(db *gorm.DB) LLMConfigRepository
  ```

  关键逻辑：
  - List：keyword 非空时 `Where("name LIKE ? OR model_id LIKE ?", esc, esc)`（esc = model.EscapeLike(keyword)，配合 `ESCAPE '\'`，account 域 ListAccounts 样板），空时不加 Where，全量返回，按 created_at 升序（保证删除转启的列表顺序稳定）。
  - FindByID：First 或 Take，ErrRecordNotFound 由 service 映射 1301。
  - Create/Update/Delete：标准 GORM 操作。Delete 物理删除。
  - Count：`Count(&domain.LLMConfig{})` 用于判断清单是否仅剩一个。
  - EnableExclusive：在事务内 `UPDATE llm_configs SET enabled=false`（全表停用）再 `UPDATE llm_configs SET enabled=true WHERE id=?`（目标启用）。调用方（service）应在事务内调用，或本方法自带 `r.db.Transaction`。

  接口：
  ```go
  type LLMConfigService interface {
      List(ctx context.Context, keyword string) ([]LLMConfigDTO, error)
      Detail(ctx context.Context, id int64) (*LLMConfigDetailDTO, error)
      Create(ctx context.Context, name, provider, modelID, apiURL, apiKeyCipher, keyID string) (*CreateLLMResult, error)
      Update(ctx context.Context, id int64, name, provider, modelID, apiURL string, apiKeyCipher, keyID string, hasAPIKey bool) (*CreateLLMResult, error)
      Delete(ctx context.Context, id int64) (*DeleteLLMResult, error)
      Enable(ctx context.Context, id int64) error
  }
  func NewLLMConfigService(repo repository.LLMConfigRepository, dec service.PasswordDecryptor, encKey []byte) LLMConfigService
  ```
  密文解密器直接复用 account 域已定义导出的 `service.PasswordDecryptor` 接口（`Decrypt(ctx, keyID, cipherB64 string) (string, error)`），由 `*rsakey.Manager` 实现，wire 已有 `wire.Bind(new(service.PasswordDecryptor), new(*rsakey.Manager))`，无需新增接口与 bind。语义上 PasswordDecryptor 承载通用 RSA-OAEP 密文解密，密码与密钥共用同一 RSA 通道与公钥接口。encKey 为 crypto.DeriveKey(config.LLM.SecretKey) 的 32 字节 key，由 wire provider 提供（见 T3 的 NewLLMEncKey）。

  关键逻辑：
  - List：repo.List → 转 []LLMConfigDTO（只取 Masked 列，不解密明文，最小暴露），created_at/updated_at 格式化为 RFC3339 字符串。
  - Detail：repo.FindByID，不存在返 NewError(LLMConfigNotFound)=1301；存在则 crypto.Decrypt(encKey, cfg.APIKeyCipher) 解密明文返 LLMConfigDetailDTO.APIKey。
  - Create 校验（任一失败 1400，message 带字段名）：name 非空且 ≤50 字符；provider ∈ {deepseek,openai,zhipu,anthropic}；model_id 非空且 ≤100 字符；api_url 为空或（非空且 URL 格式，≤500 字符）；apiKeyCipher 非空。校验通过后 dec.Decrypt(ctx,keyID,apiKeyCipher) 解密明文（失败 1400），明文 ≤200 字符校验。组装 domain.LLMConfig：APIKeyCipher=crypto.Encrypt(encKey,明文)、APIKeyMasked=crypto.Mask(明文)、Enabled=（repo.Count==0 即首个模型自动启用）。repo.Create 落库。
  - Update 校验同 Create（name/provider/model_id/api_url），id 存在性先查（不存在 1301）。hasAPIKey=false 时保留原 APIKeyCipher 与 APIKeyMasked 不变（只更新 name/provider/model_id/api_url）；hasAPIKey=true 时解密新密文、重新 Encrypt + Mask 覆盖。repo.Update 保存。
  - Delete：先 repo.FindByID（不存在 1301）；repo.Count，若 Count<=1 返 NewError(LastLLMConfig)=1302（至少保留一个）。Count>1 时事务内：判断被删模型是否 enabled，若是则 repo.FindFirstByIDOrder(被删id) 找首个剩余，记录其 id 作为 transferredEnabledID，repo.Delete 删除，再把该剩余 EnableExclusive。若被删模型非启用态，直接 Delete，transferredEnabledID=nil。返 DeleteLLMResult。
  - Enable：repo.FindByID（不存在 1301），repo.EnableExclusive(id) 事务内排他启用。
  - 错误模型复用 service.Error。

  **验收锚点：**
