# 写通道骨架 实现计划

> **目标：** 建 operation_logs 表与仓储，实现记录中间件（受保护组 POST + 登录单挂）、异步落库通道与 180 天定期清理任务，保证全部写接口与登录行为零漏记落库（未埋点接口走路径级兜底）。
> **架构：** domain 模型经 AutoMigrate 建表；repository 提供批量落库与查询消费双面五方法；middleware 新增 OperationLog 记录中间件挂 auth 组 JWT 之后与登录公开路由，响应后解析 code 判定成败、读埋点 sink 组装记录，交 Recorder 异步批量落库；worker 新增 operation-log:clean 定时清理任务。
> **技术栈：** Go 1.25 + Gin + GORM（glebarez/sqlite 多库兼容 tag）+ Asynq（清理任务 default 队列）+ Wire。
