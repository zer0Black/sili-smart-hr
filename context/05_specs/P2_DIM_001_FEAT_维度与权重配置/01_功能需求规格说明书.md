# 功能需求规格说明书

## 1. 概述

### 1.1 功能背景

sili-smart-hr 把 AI 对话日志周期性转化为能力评分，评分能否运行取决于一份统一的能力模型口径。这份口径包含能力模型的维度构成、各维度的评分提示词与评分锚点、模块内的聚合权重，以及使用活跃度的分级阈值。对话分析评估与主动测试评估都从这里读取评分口径，没有这份配置，评估引擎既不知道评哪些维度，也不知道怎么把维度分聚合成模块分与总览分。

当前这份口径以原型 [dimension-config-list.html](../../../06_prototype/01_原型/dimension-config-list.html) 为蓝本，需要一份可运行的功能把它落到系统里，供运营人员在线维护。

### 1.2 本功能业务目标

1. 提供能力模型维度构成的全量维护能力，覆盖使用活跃度、AI 使用能力、AI 管理能力、九型人格四个模块的维度新增、编辑、停用、删除。
2. 承载评分口径的可解释基础，每个对话分析维度可维护评分提示词与评分锚点，保证同一人跨评估区间、跨团队评分可比可追溯。
3. 承载聚合权重与活跃度分级阈值，作为对话分析评估与主动测试评估下次跑批的统一输入。
4. 配置改动延迟到下次评估生效，历史画像保留快照不重算，保证口径可演进的同时历史评分可解释。

## 2. 角色与权限矩阵

> 系统已全量移除角色概念，平台账号统一全权。本功能不设角色区分，所有已登录平台账号共享同一份系统级维度配置，无行级数据隔离。

### 2.1 数据权限（行级访问控制）

| 角色 | 数据范围 | 说明 |
|------|---------|------|
| 平台账号（已登录） | 全部维度配置 | 维度与权重配置是系统级单例配置，所有平台账号共享同一套口径，无创建人隔离、无部门隔离 |

### 2.2 页面访问权限

| 页面名称 | 可访问角色 | 可操作角色 | 字段级权限（如有） |
|---------|----------|----------|------------------|
| 维度与权重配置页 | 已登录平台账号 | 已登录平台账号 | 无 |
| 新增维度弹窗 | 已登录平台账号 | 已登录平台账号 | 无 |

### 2.3 接口鉴权矩阵

| 接口用途 | 方法 | 鉴权方式 | 说明 |
|---------|------|---------|------|
| 维度树查询 | GET | JWT | 返回四模块维度树完整结构 |
| 单维度详情 | GET | JWT | 选中叶子节点加载配置 |
| 维度新增 | POST | JWT | 新建叶子维度，编码系统生成 |
| 维度编辑 | PUT | JWT | 保存维度属性、权重、提示词、锚点 |
| 维度删除 | DELETE | JWT | 仅停用态可调，软删除 |
| 维度启停 | PUT | JWT | 切换 enabled 状态 |
| 活跃度规则查询 | GET | JWT | 读取活跃/低频阈值 |
| 活跃度规则保存 | PUT | JWT | 保存判定阈值 |

承载雪花 ID 的字段（维度 ID、所属模块/分组 ID）json 序列化带 `,string`，前端类型用 string，避免精度丢失。具体字段定义由下游「接口数据设计」技能落地。

## 3. 页面与功能总览

### 3.1 页面清单

| 序号 | 页面名称 | 页面形式 | 职责说明 | 包含功能 |
|-----|---------|---------|---------|---------|
| 1 | 维度与权重配置页 | 独立页面 | 单页双栏维护能力模型维度构成、评分口径、聚合权重与活跃度阈值 | 维度树浏览与搜索、叶子维度配置、活跃度规则配置、模块汇总查看、新增维度入口 |
| 2 | 新增维度弹窗 | 弹窗对话框 | 收集新维度基础属性并按模块归位 | 新增维度表单提交 |

辅助弹窗（不单列页面）：保存配置二次确认弹窗、保存活跃度规则二次确认弹窗、删除维度 popconfirm。

### 3.2 页面跳转流程

```
[入口：顶栏「系统配置 → 维度与权重」] → [维度与权重配置页]
                                              ↓ 点击「新增维度」
                                        [新增维度弹窗] → 确定后回到配置页并选中新维度
                                              ↓ 点击「保存配置」/「保存规则」
                                        [保存二次确认弹窗] → 确认后留在配置页
                                              ↓ 点击「删除维度」（停用态）
                                        [删除 popconfirm] → 确认后回到配置页并切换选中
```

**流程说明：**
1. 用户从顶栏「系统配置 → 维度与权重」进入配置页，默认展开四模块并选中首个可配置叶子维度。
2. 在左侧维度树点选节点，右侧按节点类型切换为模块/分组汇总视图、活跃度规则配置或叶子维度配置表单。
3. 点击「新增维度」打开弹窗，提交后新维度按所属模块归位并自动选中。
4. 所有保存与删除操作完成后均留在配置页，不跳转。

## 4. 页面功能详细说明

### 4.1 页面 1：维度与权重配置页

#### 4.1.1 页面概述

**页面形式：** 独立页面，挂 `_authenticated` 顶栏「系统配置」一级菜单下的「维度与权重」。

**页面职责：** 承载能力模型全部可维护内容。左侧维度树呈现四模块（使用活跃度、AI 使用能力、AI 管理能力、九型人格）的模块、分组、叶子维度三层结构；右侧配置面板根据选中节点类型切换三种形态：模块或分组节点展示所含维度的只读汇总表，使用活跃度模块展示判定阈值规则，叶子维度展示完整配置表单。页面顶部以信息条说明评分基准策略。

#### 4.1.2 涉及字段

> 本页非列表页。字段按四个逻辑组描述：左侧维度树、叶子维度配置表单、活跃度规则配置、模块汇总视图。新增维度弹窗字段见 4.2.2。

##### A. 维度树（左侧面板，浏览与搜索）

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 业务含义 |
|---------|---------|---------|---------|---------|
| 树搜索关键词 | 文本 | 用户输入 | 实时输入 | 按维度名称模糊过滤维度树 |
| 节点标签 | 文本 | 数据库查询 | 页面加载 | 模块、分组或维度名称 |
| 节点标记 | 标签 | 数据库查询 | 页面加载 | 模块/分组/参考/已停用标记 |
| 节点权重徽标 | 标签 | 数据库查询 | 页面加载 | 参与总览且非活跃度维度的权重百分比 |

##### B. 叶子维度配置表单（右侧形态 C，核心编辑字段）

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---------|---------|---------|---------|---------|--------|---------|
| 维度名称 | 文本 | 用户输入 | 实时输入 | 必填，2~30 字符 | 无 | 维度的显示名称 |
| 维度编码 | 文本（只读） | 系统生成 | 新增时生成 | 唯一，≤40 字符 | 系统生成 | 维度唯一编码，模块前缀加名称拼音 |
| 所属模块 | 标签（只读） | 系统预设 | 新增时确定 | 无 | 无 | 维度所属模块，新增后不可改 |
| 数据来源 | 标签（只读） | 系统预设 | 新增时确定 | 无 | 无 | 信号来源：对话分析/主动测试/规则统计 |
| 评分提示词 | 文本域 | 用户输入 | 实时输入 | 数据来源为对话分析时必填，≤2000 字符 | 无 | 喂给 LLM 的该维度评分指令 |
| 评分锚点 | 文本域 | 用户输入 | 实时输入 | 必填，≤500 字符 | 无 | 绝对分标准锚点，固定分值区间对应的能力表现 |
| 聚合权重 | 数字加滑块 | 用户输入 | 实时输入 | 0~100 整数 | 0 | 模块内聚合权重百分比 |
| 参与总览分 | 开关 | 用户输入 | 实时切换 | 无 | 参与 | 是否计入模块聚合与总览分 |
| 是否启用 | 开关 | 用户输入 | 实时切换 | 无 | 启用 | 是否进入评估，停用后可删除 |
| 维度说明 | 文本域 | 用户输入 | 实时输入 | ≤300 字符 | 无 | 维度的含义、信号来源与评判要点 |

权重编辑受限场景见业务规则：活跃度维度、参考性维度权重控件禁用并提示原因。

##### C. 活跃度规则配置（右侧形态 B）

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---------|---------|---------|---------|---------|--------|---------|
| 统计区间 | 标签（只读） | 系统预设 | 页面加载 | 无 | 跟随评估区间 | 活跃度随 AI 使用能力同区间统计，范围由系统配置页评估区间决定 |
| 活跃判定下限 | 数字 | 用户输入 | 实时输入 | 必填，1~999 整数 | 10 | 本评估区间有效对话达此值判为活跃 |
| 低频判定下限 | 数字 | 用户输入 | 实时输入 | 必填，1~999 整数，须小于活跃判定下限 | 5 | 达此值且低于活跃下限判为低频，低于此值判为未使用 |

##### D. 模块/分组汇总视图（右侧形态 A，只读表格）

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 业务含义 |
|---------|---------|---------|---------|---------|
| 序号 | 数字 | 计算 | 页面加载 | 行序 |
| 维度名称 | 文本 | 数据库查询 | 页面加载 | 所含维度名 |
| 数据来源 | 标签 | 数据库查询 | 页面加载 | 信号来源类型 |
| 权重 | 文本 | 数据库查询 | 页面加载 | 参与总览的展示百分比，不参与显示为「—」 |
| 参与总览分 | 标签 | 数据库查询 | 页面加载 | 是或否 |
| 状态 | 标签 | 数据库查询 | 页面加载 | 启用或停用 |

  - 触发按钮：保存规则

  - 触发方式：点击按钮

- **重置活跃度规则**
  - 触发按钮：重置规则

  - 触发方式：点击按钮
  - 权限要求：已登录平台账号

**后台自动流程：**

- **维度树与汇总加载**
  - 触发时机：页面加载时

#### 4.1.4 业务规则

- **规则1：配置生效时机**
  - 规则描述：维度属性、权重、评分提示词、评分锚点、活跃度阈值的任何保存，均在下次评估跑批时生效。
  - 触发条件：保存配置或保存规则成功。
  - 约束说明：当前评估区间已产出的历史画像不重算，仅后续评估采用新口径。

- **规则2：模块权重合计建议**
  - 规则描述：模块内参与总览且启用的维度权重建议合计 100%。
  - 触发条件：模块权重汇总条实时计算。
  - 约束说明：偏离 100% 时进度条与数值变黄、提示当前偏离值，不阻断保存。参考性维度（九型人格）不展示进度条，仅提示「参考性维度，初期不进入硬性聚合」。

- **规则3：删除前置与历史影响**
  - 规则描述：仅停用态维度可删除，启用态删除按钮禁用。
  - 触发条件：点击删除维度。
  - 约束说明：删除后已产出的历史画像保留快照不重算，仅后续评估不再产出该维度分；若该维度已配评分提示词一并删除。

- **规则4：维度编码自动生成**
  - 规则描述：维度编码由系统按模块前缀加维度名称拼音自动生成，全大写下划线连接，保证唯一。
  - 触发条件：新增维度提交时。
  - 约束说明：前缀按模块映射（AI 使用能力 AI、AI 管理能力 MGT、使用活跃度 ACT、九型人格 ENN），编码 ≤40 字符，同名维度拼音重复时追加序号去重，不可手填。

- **规则5：权重编辑受限**
  - 规则描述：使用活跃度维度、参考性维度的权重控件禁用。
  - 触发条件：选中上述维度加载表单。
  - 约束说明：活跃度维度提示「基线分级维度，不参与能力权重聚合」；参考性维度提示「参考性维度，不进入硬性聚合，权重无需配置」。

- **规则6：评分提示词适用范围**
  - 规则描述：仅数据来源为对话分析的维度需要且必须配置评分提示词。
  - 触发条件：编辑或新增对话分析维度。
  - 约束说明：主动测试维度的题目与阅卷评分表在题库管理维护，本页不配提示词；规则统计维度不调 LLM，不配提示词。未填提示词的对话分析维度无法被 LLM 评分。

- **规则7：评分锚点必填**
  - 规则描述：每个叶子维度必须维护评分锚点作为绝对分标准。
  - 触发条件：新增或编辑维度。
  - 约束说明：锚点按固定分值区间描述对应的能力表现，具体分档与区间由运营按维度自定义（如分为高/中/低三档，区间连续无空隙），保证跨区间跨团队评分可比可追溯。

- **规则8：数据来源与模块联动**
  - 规则描述：数据来源在新增时按所属模块联动确定，提交后只读。
  - 触发条件：新增维度选择所属模块。
  - 约束说明：使用活跃度对应规则统计，九型人格与 AI 管理能力对应主动测试，AI 使用能力对应对话分析。

- **规则9：操作异常反馈**
  - 规则描述：本配置页与新增维度弹窗的所有写操作（保存配置、保存规则、删除维度、提交新增）按统一策略反馈异常。
  - 触发条件：接口返回失败。
  - 约束说明：表单校验失败时字段内联报错并保留已填输入，不关闭弹窗、不切换面板；网络或服务异常 toast 提示「操作失败，请稍后重试」，允许重试；并发冲突（维度已被他人变更或删除）toast 提示「该维度配置已变更，请刷新后重试」并中止本次提交。编码冲突的特定处理见 4.2.4 规则2。

#### 4.1.5 交互逻辑

- 维度树按模块固定顺序（使用活跃度、AI 使用能力、AI 管理能力、九型人格）展示，模块内叶子维度按维度编码升序排列。
- 左侧维度树支持按维度名称实时模糊过滤，树节点高亮当前选中。
- 右侧面板按选中节点类型切换：模块或分组节点展示只读汇总表，使用活跃度模块展示规则配置，叶子维度展示配置表单，未选中展示空状态引导。
- 权重编辑器滑块与数字输入双向联动，0~100 整数步进。
- 模块权重汇总条实时计算参与总览且启用维度的权重合计，渲染百分比数值与进度条，合计为 100 显绿色对勾，偏离显黄色警示。
- 选中活跃度模块时汇总条不展示，改由判定关系说明块呈现「≥活跃下限判活跃、低频下限至活跃下限减一判低频、不足低频下限判未使用」。
- 删除成功后自动切换选中到首个可用叶子维度，无可用维度时回到空状态。
- 编辑态评分提示词字段显隐与新增态一致，仅数据来源为对话分析的维度显示（详见 4.2.5）。

#### 4.1.6 权限要求

参见第 2.2 节页面访问权限。本页面无第 2 章未覆盖的特殊权限规则。

### 4.2 页面 2：新增维度弹窗

#### 4.2.1 页面概述

**页面形式：** 弹窗对话框，宽 560px，遮罩点击不关闭，关闭即销毁。

**页面职责：** 收集新维度的基础属性，按所属模块与分组把新维度插入维度树对应位置，编码由系统自动生成。

#### 4.2.2 涉及字段

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---------|---------|---------|---------|---------|--------|---------|
| 维度名称 | 文本 | 用户输入 | 实时输入 | 必填，2~30 字符 | 无 | 维度显示名称，编码据此生成 |
| 所属模块 | 下拉 | 系统预设 | 用户选择 | 必填，四选一 | 当前选中节点所属模块 | 维度所属模块 |
| 所属分组 | 下拉 | 系统预设 | 用户选择 | 仅 AI 使用能力模块显示 | 底层能力 | 底层能力或上层能力 |
| 数据来源 | 下拉 | 系统预设联动 | 用户选择 | 必填 | 按模块联动 | 信号来源类型，提交后只读 |
| 评分提示词 | 文本域 | 用户输入 | 实时输入 | 数据来源为对话分析时必填，≤2000 字符 | 无 | 喂给 LLM 的评分指令 |
| 评分锚点 | 文本域 | 用户输入 | 实时输入 | 必填，≤500 字符 | 无 | 绝对分标准锚点，新增即确立 |
| 聚合权重 | 数字加滑块 | 用户输入 | 实时输入 | 0~100 整数 | 按模块联动（5 或 0） | 新建时的初始聚合权重 |
| 参与总览分 | 开关 | 用户输入 | 实时切换 | 无 | 按模块联动 | 是否计入模块聚合 |
| 维度说明 | 文本域 | 用户输入 | 实时输入 | ≤300 字符 | 无 | 维度含义说明 |

#### 4.2.3 功能与按钮

**用户可操作功能：**

- **提交新增维度**
  - 触发按钮：确定新增
  - 按钮级别：字段级
  - 按钮位置：弹窗底部
  - 触发方式：点击按钮
  - 权限要求：已登录平台账号
  - 加载状态：点击后至接口响应完成前 loading，防重复提交
  - 功能说明：校验表单通过后生成维度编码，校验编码唯一，按所属模块与分组插入维度树，关闭弹窗并选中新维度。

- **取消新增**
  - 触发按钮：取消
  - 按钮级别：字段级
  - 按钮位置：弹窗底部
  - 触发方式：点击按钮
  - 权限要求：已登录平台账号
  - 加载状态：否
  - 功能说明：关闭弹窗并清空已填内容。

#### 4.2.4 业务规则

- **规则1：模块联动默认值**
  - 规则描述：所属模块切换时，数据来源、聚合权重、参与总览分按模块联动重置。
  - 触发条件：切换所属模块。
  - 约束说明：使用活跃度强制规则统计、权重 0、不参与总览；九型人格强制主动测试、权重 0、不参与总览且标记参考性；AI 管理能力强制主动测试、权重 5、参与总览；AI 使用能力强制对话分析、权重 5、参与总览。

- **规则2：编码生成与唯一校验**
  - 规则描述：提交时按规则 4（4.1.4）生成编码，若编码已存在则报错提示稍后重试。
  - 触发条件：提交新增维度。
  - 约束说明：编码冲突不自动改写，由用户重新提交触发再次生成。

#### 4.2.5 交互逻辑

- 所属分组字段仅在所属模块为 AI 使用能力时显示。
- 评分提示词字段仅在数据来源为对话分析时显示，配套说明「未填写评分提示词的对话分析维度无法被 LLM 评分」。
- 数据来源为主动测试时展示配套说明，提示题目与阅卷评分表在题库管理维护。

#### 4.2.6 权限要求

参见第 2.2 节页面访问权限。本弹窗无第 2 章未覆盖的特殊权限规则。

### 7.1 外部系统集成

无直接外部系统集成。评分提示词与权重为本系统自有配置，PRD 4.8.5 明确无外部依赖。

### 7.2 内部功能依赖

| 当前功能 | 依赖的功能 | 依赖说明 | 依赖类型 |
|---------|-----------|---------|---------|
| 维度与权重配置 | 登录与用户管理（P1_ACC_001） | 本页挂 `_authenticated` 顶栏，依赖账号模型与 JWT 鉴权基建 | 权限依赖 |
| 对话分析评估（未建） | 维度与权重配置 | 读取 AI 使用能力各维度的评分提示词、评分锚点、聚合权重作为评分与聚合口径 | 数据依赖（被依赖） |
| 主动测试评估（未建） | 维度与权重配置 | 读取 AI 管理能力各维度聚合权重作为模块聚合口径 | 数据依赖（被依赖） |
| 大模型配置（未建） | 维度与权重配置 | 评分提示词经评估引擎喂给当前排他启用的唯一 LLM 模型 | 流程依赖（运行时，配置侧不直接调用） |
| 系统配置（未建） | 维度与权重配置 | 活跃度统计区间跟随系统配置页定义的评估区间，统计范围由评估区间决定 | 数据依赖（被依赖） |

本功能向上被评估两条主线（对话分析、主动测试）依赖，是评估能否运行的配置前提；向下产出维度配置供评估引擎读取。下游模块未建，依赖方向已在 PRD 4.8.6 与架构文档确认。

### 8.1 术语表

| 术语 | 定义 | 说明 |
|------|------|------|
| 维度 | 能力模型的最小评判单元 | 分属四个模块，是评分与聚合的基本单位 |
| 模块 | 维度的顶层归属 | 使用活跃度、AI 使用能力、AI 管理能力、九型人格 |
| 评分提示词 | 喂给 LLM 的维度评分指令 | 仅对话分析维度需要，包含角色设定、信号来源、评分锚点引用与输出格式；与「评分锚点」字段独立维护 |
| 评分锚点 | 维度绝对分标准描述 | 固定分值区间对应的能力表现，保证评分可比可追溯 |
| 聚合权重 | 维度在模块内的权重百分比 | 用于把维度分聚合成模块分与总览分 |
| 参与总览分 | 维度是否计入模块聚合 | 关闭后该维度不计入模块聚合与总览分 |
| 参考性维度 | 仅作画像补充解读的维度 | 如九型人格，不进入硬性聚合 |
| 评估区间 | 系统配置页定义的跑批周期 | 活跃度统计范围跟随评估区间 |
| 使用活跃度 | 按会话频率分级的基线 | 规则统计型，不参与能力权重聚合，是能力评分的前提 |
