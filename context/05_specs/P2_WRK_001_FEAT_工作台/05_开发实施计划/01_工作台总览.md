# 工作台总览 实现计划

> **目标：** 登录后默认落地的工作台首页：单一聚合接口 GET /api/workspace 一次返回四区块数据（态势与待处理统计卡、团队能力演进、画像速览、需关注人群），前端根路由 `/` 渲染四区块并提供八个跳转入口。
> **架构：** 后端独立 WorkspaceService 编排（03 §4.1，不复用 DashboardService 接口），共享 service 包内既有聚合纯函数与 DashboardQueryRepository 方法，新增 workspace_query.go 六个只读仓储方法，任一数据源失败区块降级不整体报错（03 §1.3）。前端 workspace feature（api/hooks/types + components）替换 `/` 占位页，跳转全部经前端路由 search 参数承接，F7 评测运营中心补 tab/status URL 预填能力。
> **技术栈：** 后端 Go 1.25（Gin/GORM/Wire，fake 仓储单测）；前端 React 19 + TypeScript（TanStack Query/Router、Recharts、i18next workspace 命名空间）。
