> **目标：** 实现 Scorer 多维打分与聚合（能力5）、Evaluator.EvaluatePerson 单人周期原子入口（能力6）、Asynq person-evaluate 任务注册与 Wire 全链装配，同步更新规约文档状态描述，交付可跑通的开发验收链路。

    ```go
    // Scorer 多维打分与聚合组件（specs §2.4 能力5）。
    type Scorer struct { /* scoreRepo、aggRepo（未导出字段） */ }
    func New(scoreRepo repository.DimensionScoreRepository, aggRepo repository.AggregateScoreRepository) *Scorer

    // IncludedWeight included_json 序列化单元（specs §2.3）。
    type IncludedWeight struct {
        Code   string `json:"code"`
        Weight int    `json:"weight"`
    }

    // AggregateResult 聚合结果（specs §2.3）。
    type AggregateResult struct {
        ModuleScores map[string]*float64
        Overview     *float64
        Included     map[string][]IncludedWeight
        Excluded     map[string][]string

    // Aggregate 重算单人周期聚合行（读全部 source 评分行），幂等（specs §2.4 能力5）。

    // roundHalfUp 一位小数舍入（specs §2.4 能力5 注意事项）。
    func roundHalfUp(v float64) float64
    ```
  - 关键逻辑：
    - **读数**：scoreRepo.ListByPersonPeriodExact 双界精确读全 source 行（含 F7 active_test 行）；读失败 wrap ErrScoreRead 上抛。
    - **行分类**：status=failed → Excluded[module] 追加；status=success 且 Insufficient → Excluded[module] 追加；success 且非 insufficient 且 evidence_json 口径摘要 in_overview=true → 参与集；in_overview=false（参考性维度）不进聚合也不进 Excluded。
    - **权重来源**：逐行解析 evidence_json 的维度口径摘要（weight、in_overview 字段），不从 dimension 域现读（specs §2.4 能力1 注意事项：防当期重算引入新权重）；evidence_json 解析失败的行按剔除处理并进 Excluded（防御坏行阻断聚合）。
    - **模块分**：按 Module 分组，参与维度 `Σ(score×weight)/Σweight`，roundHalfUp 一位小数；组内空（全剔除或无参与维）→ nil。
    - **总览分**：跨模块全部参与维度直接加权平均，roundHalfUp；无任何参与维度 → nil。
    - **落库**：每模块一行 + overview 哨兵行（module="overview"、ModuleScore=nil、OverviewScore=总分）组装 []domain.AggregateScore，included_json/excluded_json 序列化；aggRepo.UpsertAll；落库失败 wrap ErrStoreWrite。
  - 依赖：`internal/repository`、`internal/domain`、`internal/engine/activity`（Period）
