# AI阅卷评分 实现计划

> **目标：** AI 阅卷链路闭环：九型判型结果表建表、grading 阅卷引擎（prompt/schema/落库/聚合自调）、CompleteTask/StartSession 对 F8 的服务契约（事务内三步推进 + 阅卷任务投递）、assessment:test-grade worker 任务与 240s 专用 LLM client。
> **架构：** 阅卷引擎独立子域 internal/engine/grading（与 evaluator/questiongen 同级同构：专用 LLM client 注入 + 窄接口读通道 + 结果落库），ai_mgmt 评分走既有 dimension_scores（source=active_test）并自调 scorer.Aggregate 刷新聚合，enneagram 判型落独立 assessment_test_results 表（参考性口径不进聚合）。触发链路：F8 提交接口调本域 service.CompleteTask（事务内任务转 completed + 链接 used + 阅卷状态 grading + 投递任务），worker 消费执行阅卷。F8 未建前生产无触发路径，测试经 service 方法与任务 handler 直接驱动。
> **技术栈：** Go 1.25 + Asynq + GORM + Wire；LLM 底座 llm.Client（专用 client 装配）。
