# 团队看板 前端看板页面 实现计划

> **目标：** 交付团队看板页（区间切换、活跃度概览、两模块雷达与共性短板、九型构成、培训建议）与能力逐期趋势页（综合分摘要、维度走势分面、变化表），完成 F9 人员画像列表页的 URL 参数预填改造与顶栏导航接通。
> **架构：** 新建 features/dashboard 域三件套（api.ts/hooks.ts/types.ts + components），DTO 进 lib/contracts.ts 按域分段；两页面为 _authenticated 独立路由（/dashboard、/dashboard/trend），图表复制 profile 域 Recharts 私有组件形态；F9 预填循 question-bank 的 validateSearch 深链先例，一次性消费后清参；导航为 nav-menu.tsx 现有灰显占位 leaf 接 to 激活。
> **技术栈：** React 19 + TypeScript、TanStack Router/Query、shadcn/ui、Tailwind 4 token、Recharts、i18next（新增 dashboard 命名空间）。
