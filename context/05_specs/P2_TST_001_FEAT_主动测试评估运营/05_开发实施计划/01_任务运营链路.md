# 任务运营链路 实现计划

> **目标：** 主动测试任务的可发起、可追踪、可管理：三表建表（tasks/links）、七接口（列表/轮询计数/发起/量表就绪/链接查询/重发/取消）、逾期 tick 定时判定，以及前端评测运营中心两 tab、发起弹窗两卡片激活与作答链接弹窗。
> **架构：** 后端按 account/批次域四层样板新建 assessment_test 域（domain → repository → service → handler → router → wire），逾期判定走独立 Asynq 任务每分钟 tick（与 batch-tick 并列注册）。前端在 F6 已建的评测运营中心页 tab 容器叠加两 tab（两实例常驻挂载保筛选独立），发起弹窗激活两张置灰卡片（类型切换重构为三态可选），作答链接弹窗新建。阅卷链路归子计划 02，本计划完成时系统口径自洽：任务停留待作答/已逾期/已取消三态，无触发进行中/已完成/已评分的路径。
> **技术栈：** Go 1.25 + Gin + GORM + Asynq + Wire；React 19 + TanStack Query + react-hook-form + Zod + shadcn/ui + i18next。
