# 跑批编排引擎 实现计划

> **目标：** 实现 pipeline.Orchestrator（CreateBatch 建批/SubmitManualBatch 手动入口/RunBatch 全流程编排）与两个 Asynq 任务（batch-tick 每分钟判定、batch-run 批次编排），完成 Wire 全链装配，让周期触发与手动发起两条路都能驱动 T4 抽取与 T5 评估。
> **架构：** Orchestrator 是批次状态机唯一持有者：建批时落名单快照（全员经 userapi 拉取），RunBatch 展开会话列表（全量串行翻页 + session_key 去重 + token_name 分组）、逐会话投递抽取任务、逐人并发（4 路）进程内直调 EvaluatePerson、单人终态原子推进、终态时算比例写告警。batch-tick 用每分钟判定替代动态 cron 重注册（03 §1.4 技术修正）。
> **技术栈：** Go 1.25、Asynq（任务投递与调度）、conversationlog/userapi 客户端、evaluator.EvaluatePerson、fallback.Retry、semaphore（并发上限）

    - 日志只输出批次号、计数、token_name 与错误码，禁输出档案内容与 prompt 文本（03 §4.4 日志规范）。
