# 后端画像域 实现计划

> **目标：** 打通个人画像域后端全链：只读仓储查询扩展、profile service 两接口（A1 列表聚合 / B1 详情聚合）、A2 xlsx 导出、handler/router/wire 装配，前端可据契约消费。
> **架构：** 按既有四层同构扩展：repository 只加只读查询方法（不动写路径），service 编排 userapi 名单 + 四表批量 IN 组装（03 §4.3 查询契约），handler 全 GET 挂 auth 组，Wire 装配经 go generate 再生。零 LLM、零写库、零新表。
> **技术栈：** Go 1.25 + Gin + GORM（三库方言兼容）+ userapi 客户端（WalkStaffPages）+ excelize（xlsx 导出，新增依赖）+ Asynq 生态外纯 HTTP。
