# 操作日志页 实现计划

> **目标：** 前端 /system/operation-log 页面：筛选区四项（操作人/操作类型/操作结果/时间范围）+ 六列日志列表 + 分页 + xlsx 导出 + 操作详情弹窗（变更对比表与文本详情互斥渲染），接通顶栏导航 F12 占位。
> **架构：** 按 account 七步样板走：feature 三件套（api/hooks/types）+ operation-log-table 组件（筛选与分页内部自治，profile-table 样板）+ detail-dialog 组件 + route 文件 + i18n 双语 + nav-menu 接通。导出复用 profile 的 blob Content-Type 判别模式。
> **技术栈：** React 19 + TanStack Query + shadcn/ui 既有原子件 + i18next（新增 operationLog 命名空间）。

    export interface ChangeItem { field: string; before: string; after: string }

    }

    export function useOperationLogExport(): UseMutationResult<{ blob: Blob; filename: string }, ApiError, Omit<OperationLogFilter, 'page' | 'page_size'>>
    // module-meta.ts
    export const moduleI18nKeys: Record<string, string>  // 八类 → 'operationLog:module.login' 等
    export type ModuleBadgeTone = 'default' | 'secondary' | 'destructive' | 'outline'
    export const moduleBadgeTone: Record<string, ModuleBadgeTone>  // 八类 → Badge variant（badge.tsx 实际六 variant 中取四）
