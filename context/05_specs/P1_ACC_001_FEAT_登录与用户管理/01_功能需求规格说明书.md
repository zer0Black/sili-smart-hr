# 登录与用户管理 功能需求规格说明书

## 文档信息

- 基线 Feature：无
- 变更组：无

---

## 1. 概述

### 1.1 功能背景

sili-smart-hr 是面向企业内部的综合人才测评平台，平台账号统一全权，登录即拥有全部功能。账号体系由平台自管，登录校验基于本台账，与业务评估场景无数据依赖，相对独立。

后端 account 登录链路（POST /api/login、GET /api/me）已作为可运行样板部分交付，本 Feature 在其上补齐用户管理业务面并固化登录认证规格：把平台访问的登录认证与可登录账号台账维护合并为一个自包含的业务单元，作为平台可登录、可运营的前置基础设施。平台不设角色权限模型，全系统无员工编号概念，台账与人员界面均不出现工号字段。

### 1.2 本功能业务目标

1. 提供平台账号登录入口，登录成功签发 JWT 写入前端持久存储，token 过期触发登出，闭合鉴权链路。
2. 提供账号台账维护能力，覆盖新增、查询、编辑、启停、删除、重置密码，启用状态与登录校验即时生效。
3. 收敛登录时序侧信道，账号不存在、密码错误、账号禁用三条路径统一返回凭证错误，避免账号枚举。

### 3.1 页面清单

| 序号 | 页面名称 | 页面形式 | 职责说明 | 包含功能 |
|-----|---------|---------|---------|---------|

### 3.2 页面跳转流程

```
未登录访问 → [登录页] → 登录成功 → [工作台]
                              ↓
            顶部导航「系统配置 > 用户管理」
                              ↓
                    [用户管理列表页]
          ├─ 新增账号 → [新增账号弹窗]
          ├─ 行内编辑 → [编辑账号弹窗]
          ├─ 行内重置密码 → [重置密码弹窗]
          ├─ 行内删除 → 删除二次确认
          └─ 行内启停开关 → 启停切换
顶栏用户菜单「退出登录」→ [登录页]
```

**流程说明：** 未登录访问任意路由统一导向登录页；登录成功跳工作台；之后经顶部导航进入用户管理列表页，列表页行内操作分别打开对应弹窗或触发确认；顶栏退出登录回到登录页。

## 4. 页面功能详细说明

### 4.1 登录页

#### 4.1.1 页面概述

**页面形式：** 独立页面，不挂 _authenticated 布局，路由 /login。

**页面职责：** 未登录用户的唯一入口。校验账号密码，成功签发 JWT 写入前端持久存储（Zustand persist，localStorage key `sili-smart-hr-auth`）并跳转工作台；已登录用户访问登录页自动重定向到工作台。

#### 4.1.2 涉及字段

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---------|---------|---------|---------|---------|--------|--------|
| 账号 | 文本 | 用户输入 | 实时输入 | 必填，自动去前后空格 | 无 | 登录账号 |
| 密码 | 密码 | 用户输入 | 实时输入 | 必填 | 无 | 登录密码，前端以 RSA-OAEP 公钥加密为密文传输，后端私钥解密后 bcrypt 比对 |

#### 4.1.3 功能与按钮

- **账号密码登录**
  - 触发按钮：登录
  - 按钮级别：页面级
  - 按钮位置：登录表单底部
  - 触发方式：点击或回车提交
  - 权限要求：无（未登录可操作）
  - 加载状态：点击后显示 loading 至接口响应
  - 功能说明：前端先做必填校验，通过后用进入页面时获取的 RSA 公钥（node-forge，RSA-OAEP）加密密码，提交 {username, passwordCipher, keyId} 调用登录接口。

- **忘记密码**
  - 触发按钮：忘记密码？（文字链）
  - 按钮级别：页面级
  - 按钮位置：登录表单内
  - 触发方式：点击
  - 权限要求：无
  - 加载状态：无
  - 功能说明：点击弹出提示"请联系系统管理员重置密码"。首期无邮件与短信自助找回通道，账号重置由管理员在用户管理页执行。

**后台自动流程：**

- **获取 RSA 公钥**
  - 触发时机：进入登录页加载时
  - 说明：前端自动调用公钥接口（参考 GET /api/auth/public-key）取 RSA 公钥与 keyId，供登录提交时加密密码。公钥失败时阻断登录提交并提示重试。

#### 4.1.4 业务规则

- **规则1：登录反枚举**
  - 规则描述：账号不存在、密码错误、账号禁用、RSA 解密失败（keyId 过期、私钥不存在或密文损坏）四类路径统一返回凭证错误（errcode 1001 InvalidCredentials），不暴露账号是否存在或是否被禁用。
  - 触发条件：每次登录校验。
  - 约束说明：四类路径各执行一次等效 bcrypt 比对以收敛时序侧信道，顺序敏感，先 RSA 解密再 bcrypt 再判 Enabled；errcode 定义了 AccountDisabled（1002），但登录路径刻意不返回。

- **规则2：密码传输加密**
  - 规则描述：所有提交密码的入口（登录、新增账号、编辑改密码、重置密码）密码字段一律前端 RSA-OAEP 加密为密文传输，明文不落请求体。
  - 触发条件：每次密码提交。
  - 约束说明：进入登录页或打开含密码字段的弹窗时前端先调公钥接口取公钥与 keyId；后端按需生成 RSA 密钥对，私钥以 keyId 关联存 Redis（复用 Asynq 已有 Redis），TTL 5 分钟，解密成功后即删做到一次性；公钥接口需限流防滥用。

- **规则3：密码存储加密**
  - 规则描述：密码以 bcrypt 哈希存储，不可逆。
  - 触发条件：新增账号、改密码、重置密码写入。
  - 约束说明：库中只存 PasswordHash，任何序列化与列表、详情均不回显明文，列表密码列仅掩码占位。

- **规则4：登录成功态处理**
  - 规则描述：登录成功签发 JWT，前端写入持久存储并跳转工作台。
  - 触发条件：登录接口返回成功。
  - 约束说明：token 过期，或后续任意请求收到 HTTP 200 + code 1003，触发登出（清 token、清查询缓存、跳 /login）。

#### 4.1.5 交互逻辑

- 已登录用户访问 /login 自动重定向到工作台。
- 登录失败统一提示"账号或密码错误"，前端登录页只识别凭证错误与通用错误两类，不区分失败原因。
- 移除原型中的"记住我"复选框与"演示入口"区块：持久存储已承载 token 持久化，无需额外开关；项目正式开发，禁用演示模式措辞。
- keyId 过期或解密失败时，前端提示并重新获取公钥后允许重试，不向用户暴露具体失败原因。

### 4.2 用户管理列表页

#### 4.2.1 页面概述

**页面形式：** 独立页面，挂 _authenticated 顶栏布局，路由 /system/users，经顶部导航「系统配置 > 用户管理」进入。

**页面职责：** 账号台账查询与维护入口。平台账号在此新增、查询、编辑、启停、删除账号并重置密码。

#### 4.2.2 涉及字段

##### A. 查询字段

| 字段名称 | 字段类型 | 数据来源 | 默认值 | 业务含义 |
|---------|---------|---------|--------|--------|
| 关键词 | 文本 | 用户输入 | 空 | 模糊匹配账号与姓名 |

##### B. 显示字段

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 业务含义 |
|---------|---------|---------|---------|--------|
| 账号 | 文本 | 数据库查询 | 页面加载与查询 | 登录账号，列表主展示项 |
| 姓名 | 文本 | 数据库查询 | 页面加载与查询 | 账号关联真实姓名，账号列副行展示 |
| 密码 | 掩码 | 系统预设 | 页面加载 | 列表仅展示掩码占位，不回显明文 |
| 启用状态 | 开关 | 数据库查询 | 页面加载 | 启用或停用，行内可切换 |
| 最近登录 | 时间 | 数据库查询 | 页面加载 | 最近一次登录成功时间，空值显示 - |

> 全系统无工号，列表不出现工号列，关键词搜索不支持工号匹配。

#### 4.2.3 功能与按钮

- **新增账号**
  - 触发按钮：新增账号
  - 按钮级别：页面级
  - 按钮位置：表格工具栏右侧

  - 权限要求：平台账号
  - 加载状态：无（仅打开弹窗）
  - 功能说明：打开新增账号弹窗。

- **查询**
  - 触发按钮：搜索框
  - 按钮级别：页面级
  - 按钮位置：表格工具栏左侧
  - 触发方式：手动输入模糊搜索
  - 权限要求：平台账号
  - 加载状态：查询时表格 loading
  - 功能说明：按账号或姓名模糊匹配列表数据。

- **编辑**
  - 触发按钮：编辑（行内链接按钮）
  - 按钮级别：行级
  - 按钮位置：操作列
  - 触发方式：点击
  - 权限要求：平台账号
  - 加载状态：无（仅打开弹窗）
  - 功能说明：打开编辑账号弹窗，回填当前账号信息，账号字段只读。

- **重置密码**
  - 触发按钮：重置密码（行内链接按钮）
  - 按钮级别：行级
  - 按钮位置：操作列
  - 触发方式：点击
  - 权限要求：平台账号
  - 加载状态：无（仅打开弹窗）
  - 功能说明：打开重置密码弹窗。

- **删除**
  - 触发按钮：删除（行内链接按钮）
  - 按钮级别：行级
  - 按钮位置：操作列
  - 触发方式：点击
  - 权限要求：平台账号
  - 加载状态：二次确认后提交，至接口响应前 loading
  - 功能说明：弹出二次确认，确认后软删除该账号。

- **启停切换**
  - 触发按钮：启用状态开关（行内）
  - 按钮级别：字段级
  - 按钮位置：启用状态列
  - 触发方式：点击开关
  - 权限要求：平台账号
  - 加载状态：切换提交至接口响应前开关 loading
  - 功能说明：切换账号启用状态，最后一个启用账号不可停用（详见 4.2.4 规则2）。

**后台自动流程：**

- **列表加载**
  - 触发时机：页面加载与查询条件变更
  - 说明：前端自动拉取账号台账分页数据。

#### 4.2.4 业务规则

- **规则1：账号唯一**
  - 规则描述：账号全局唯一。
  - 触发条件：新增提交。
  - 约束说明：账号重复返回"账号已存在"；编辑模式账号不可改，无需重校。

- **规则2：至少保留一个启用账号**
  - 规则描述：系统任何时刻至少保留一个启用账号，避免无人可登录。
  - 触发条件：停用、删除、编辑降为停用时。
  - 约束说明：当被操作账号是最后一个启用账号时，停用、删除、编辑降停被拦截，提示"至少保留一个启用的账号"。

- **规则3：启停即时生效**
  - 规则描述：启用状态切换即时写入，停用账号即时无法登录。
  - 触发条件：启停提交成功。
  - 约束说明：停用账号再次登录走凭证错误路径。

- **规则4：删除为软删除**
  - 规则描述：删除账号为逻辑删除，列表不再展示。
  - 触发条件：删除二次确认通过。
  - 约束说明：软删除账号不参与账号唯一性校验，账号名可被重新创建。

#### 4.2.5 交互逻辑

- 关键词为空时展示全部账号，无匹配结果时展示空状态。
- 新建账号插入列表顶部便于确认。

### 4.3 新增/编辑账号弹窗

#### 4.3.1 页面概述

**页面形式：** 弹窗对话框。

**页面职责：** 新增模式下录入新账号（含初始密码），编辑模式下修改姓名与启用状态、可选重置密码。新增与编辑共用同一弹窗，靠模式区分字段必填性与账号可编辑性。

#### 4.3.2 涉及字段

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---------|---------|---------|---------|---------|--------|--------|
| 账号 | 文本 | 用户输入 | 实时输入 | 必填；3 到 30 位字母、数字或下划线；全局唯一；自动去前后空格 | 无 | 登录账号，保存后不可修改 |
| 姓名 | 文本 | 用户输入 | 实时输入 | 必填；上限 20 字符 | 无 | 真实姓名 |
| 密码 | 密码 | 用户输入 | 实时输入 | 新增必填、编辑选填；不少于 8 位且同时含字母与数字 | 无 | 登录密码，前端 RSA-OAEP 加密传输，编辑模式留空表示不改 |
| 启用状态 | 开关 | 用户输入 | 实时输入 | 无 | 新增默认启用 | 控制账号可否登录 |

#### 4.3.3 功能与按钮

- **保存（新增为"确定新增"、编辑为"保存修改"）**
  - 触发按钮：弹窗底部确定
  - 按钮级别：字段级
  - 按钮位置：弹窗底部
  - 触发方式：点击
  - 权限要求：平台账号
  - 加载状态：提交至接口响应前 loading
  - 功能说明：新增模式创建账号；编辑模式更新姓名、可选密码、启用状态。提交前做表单校验、账号唯一性校验与至少保留一个启用账号校验；密码字段先经 RSA-OAEP 加密再提交。

- **取消**
  - 触发按钮：弹窗底部取消
  - 按钮级别：字段级
  - 按钮位置：弹窗底部
  - 触发方式：点击
  - 权限要求：平台账号
  - 加载状态：无
  - 功能说明：关闭弹窗并重置已填内容。

#### 4.3.4 业务规则

- **规则1：账号唯一性与不可改**
  - 规则描述：账号全局唯一，创建后不可修改。
  - 触发条件：新增提交。
  - 约束说明：编辑模式账号字段只读；新增重复返回"账号已存在"。

- **规则2：编辑降停保留校验**
  - 规则描述：编辑模式将启用账号改为停用时，若它是最后一个启用账号则被拦截。
  - 触发条件：编辑提交且启用状态由启用变为停用。
  - 约束说明：提示"至少保留一个启用的账号"。

#### 4.3.5 交互逻辑

- 新增模式密码必填，编辑模式密码占位提示"留空保持原密码不变"。
- 账号字段编辑模式禁用，灰显只读。

### 4.4 重置密码弹窗

#### 4.4.1 页面概述

**页面形式：** 弹窗对话框。

**页面职责：** 单独为指定账号设置新密码，重置后原密码立即失效。弹窗顶部只读展示目标账号与姓名。

#### 4.4.2 涉及字段

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---------|---------|---------|---------|---------|--------|--------|
| 新密码 | 密码 | 用户输入 | 实时输入 | 必填；不少于 8 位且同时含字母与数字 | 无 | 重置后的新密码，前端 RSA-OAEP 加密传输 |

#### 4.4.3 功能与按钮

- **确认重置**
  - 触发按钮：弹窗底部确认重置
  - 按钮级别：字段级
  - 按钮位置：弹窗底部
  - 触发方式：点击
  - 权限要求：平台账号
  - 加载状态：提交至接口响应前 loading
  - 功能说明：提交新密码，校验通过后写入，原密码立即失效；密码字段先经 RSA-OAEP 加密再提交。

- **取消**
  - 触发按钮：弹窗底部取消
  - 按钮级别：字段级
  - 按钮位置：弹窗底部
  - 触发方式：点击
  - 权限要求：平台账号
  - 加载状态：无
  - 功能说明：关闭弹窗。

#### 4.4.4 业务规则

- **规则1：重置即时失效**
  - 规则描述：重置成功后原密码立即失效，新密码即时可用于登录。
  - 触发条件：重置提交成功。
  - 约束说明：停用账号亦可重置密码，重置不改变启用状态。

#### 4.4.5 交互逻辑

无额外交互逻辑。

## 5. 非页面功能详细说明（无）

本 Feature 无独立的定时任务、API 服务或数据同步类非页面功能，所有业务流程由页面触发。

**归属边界说明：** 登录认证的 JWT 签发、密码 bcrypt 哈希、反枚举时序收敛属于平台运行基座（技术泳道 T1）的技术实现，不在本业务 Feature 承载；RSA 动态密钥管理（密钥对生成、私钥以 keyId 关联缓存、TTL 控制、解密成功即删）虽复用 T1 已有的 Redis 基础设施，但其生命周期管理属本 Feature 登录接口的内部传输安全流程，随登录接口在 interface 阶段设计承载，不单列为独立非页面功能。

## 6. 数据状态定义

账号仅含启用状态一个状态维度，叠加软删除形成终态。

### 6.1 数据状态

| 状态名称 | 状态说明 | 可转换到的状态 |
|---------|---------|--------------|
| 启用 | 账号可正常登录 | 停用、已删除 |
| 停用 | 账号无法登录，登录走凭证错误路径 | 启用、已删除 |
| 已删除 | 软删除，列表不展示，账号名可复用 | 无（终态） |

### 6.2 状态转换规则

| 当前状态 | 可转换到的状态 | 转换条件 | 转换触发方式 |
|---------|------------|---------|-------------|
| 启用 | 停用 | 该账号非最后一个启用账号 | 用户操作（启停开关或编辑弹窗） |
| 停用 | 启用 | 无约束 | 用户操作（启停开关或编辑弹窗） |
| 启用 | 已删除 | 该账号非最后一个启用账号 | 用户操作（删除二次确认） |
| 停用 | 已删除 | 无约束 | 用户操作（删除二次确认） |
