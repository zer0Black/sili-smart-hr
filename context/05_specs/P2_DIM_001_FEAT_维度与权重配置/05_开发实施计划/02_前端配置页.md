# 维度与权重配置 实现计划 — 子计划2：前端配置页

> **目标：** 落地维度与权重配置页（双栏：左侧维度树 + 右侧按节点类型切换三种形态），挂 _authenticated 顶栏「系统配置 → 维度与权重」。
> **架构：** 照 account feature 样板走七步（contracts → feature 三件套 → route → i18n）。模块/分组/数据来源为前端硬编码常量（不入库），集中在 types.ts 作为单一来源，所有组件引用同一常量消除耦合。右侧三形态靠选中节点类型条件渲染，状态在 route 组件用 useState 管理。
> **技术栈：** React 19 + TypeScript、TanStack Router/Query、shadcn/ui（new-york）、Tailwind 4、React Hook Form + Zod、i18next。

---
